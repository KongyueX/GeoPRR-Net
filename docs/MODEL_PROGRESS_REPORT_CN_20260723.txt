RobustPointerMeterReading 模型修改、性能提升与阶段成果报告
日期：2026-07-23
项目：PointerMeterReaderFastAPI / RobustPointerMeterReading

说明
====

本报告记录截至 2026-07-23 已完成并实际运行的代码修改、训练、验证、冻结测试和消融实验。
报告中的数值均来自 artifacts/runs/ 下的自动生成结果，不是预估值。
大模型权重和逐样本预测不提交 Git；训练、评估、汇总和严格验证脚本提交到代码仓库。


一、原始系统与主要问题
======================

原始读数链路主要依赖：

1. YOLO 检测表盘；
2. U2Net 分割指针；
3. 几何方法和 Transformer 估计指针位置；
4. 起点/终点参考角与已知量程将角度换算成读数。

原始链路在清晰、正视图像上可以工作，但存在三个主要问题：

1. 指针分割失败时，整个读数链路容易无输出；
2. 模糊、反光和透视会破坏细指针掩膜及中心线校验；
3. 合成域到 RPM-10K 真实域的覆盖率和平均误差存在明显差距。


二、已经完成的模型修改
======================

2.1 分割和几何主分支改进
------------------------

1. 修复 U2NetP letterbox 输出恢复时的坐标问题；
2. 使用 SyncG train 对 U2NetP 做域内微调；
3. 采用 BCE + Dice 深监督，并只在真实内容区计算损失；
4. 在分组验证集上冻结分割阈值；
5. 增加 Geometry-v1、Geometry-v2 和质量加权几何融合；
6. 增加跨量程归一化残差校正与选择性门控；
7. 所有失败样本均计入主指标：NMAE 按 1.0 惩罚，Acc 计错，并单独报告 coverage。

分割组件结果：

Released calibrated Micro Dice：0.248642
SyncG fine-tuned Micro Dice：   0.912560
绝对提升：                     0.663918

这证明分割域适配有效，但 U2Net、Dice loss 和普通微调本身不应作为论文首创点。


2.2 掩膜—方向双表示
------------------

新增与分割分支独立的方向专家：

1. ResNet-18 编码器；
2. 64×64 支点热图头；
3. 二维直接方向向量头；
4. 不依赖指针掩膜，在掩膜分支失败时提供硬回退；
5. 后续再通过训练侧 grouped-OOF 路由处理“两个分支都有输出但质量不同”的样本。

第一版方向专家显著提高了真实域覆盖率。RPM-10K single-pointer 子集上，双表示硬回退将
coverage 从 72.73% 提高到 98.78%，恢复了 468/490 个原分支失败请求。


2.3 概率圆周方向头（当前 v2）
----------------------------

在第一版方向专家上新增：

1. 72-bin 圆周概率分布头；
2. 直接向量头与圆周分布头的联合方向解码；
3. 异方差角度 log-variance 头；
4. 圆周软标签，避免 0°/360° 边界不连续；
5. 输出角度标准差、圆周熵、resultant length、支点空间熵和 top-2 margin；
6. 只增加约 18,761 个参数，约为 v1 的 0.13%。

该修改的主要作用不是简单增加网络容量，而是：

1. 显式建模方向的周期性；
2. 让两个方向估计器互相校验；
3. 给路由器提供原生的不确定性信号；
4. 对模糊和多峰方向预测给出可解释置信度。


2.4 精确投影配对监督与透视等变正则
----------------------------------

训练时为同一图像生成虚拟 yaw/pitch 透视视图，并通过同一单应矩阵精确变换：

1. 指针支点；
2. 指针针尖；
3. 方向射线；
4. 支点热图标签。

损失由三部分组成：

1. 原图监督损失；
2. 投影视图的精确监督损失；
3. 将两视图输出映射到同一坐标系后的等变一致性损失。

该设计直接针对倾斜拍摄和极端拍照角度，不把透视图简单当作标签不变的数据增强。


2.5 不确定性感知路由与软融合
----------------------------

新增两种融合方式并分别验证：

1. 双方差软融合：学习 mask/vector 两个专家的方差，再按逆方差连续加权；
2. 不确定性感知选择性路由：预测 vector 相对 mask 的归一化误差收益，只在预计收益超过
   阈值时切换；mask 失败时仍强制尝试 vector，两个分支都失败时保持失败。

路由训练严格使用 SyncG train 的 grouped out-of-fold 预测：

样本数：4,380
仪表组：197
共同成功样本：4,349
组泄漏：0
测试样本用于拟合：0

软融合是有价值的负消融：它在训练 OOF 上略有改善，但大多数冻结测试条件不如选择性路由。
这说明两个专家的误差不是适合逐样本平均的同方差噪声，困难样本更适合离散切换。


2.6 可复现实验与审计
--------------------

新增并实际运行：

1. 三随机种子完整训练；
2. train/validation 按仪表组划分，组交集为 0；
3. clean、两级模糊、两级透视、严重联合退化和 RPM-10K 冻结评估；
4. 按 group_id 的 5,000 次成对 bootstrap 95% 置信区间；
5. 方向解码器消融；
6. 等变损失和投影配对训练消融；
7. 路由特征消融；
8. 检查点、数据清单、源文件和预测文件 SHA-256 绑定；
9. 独立验证脚本重新检查训练轮数、优化步、组交集、路由决策和主指标。


三、方向模型的实际提升
======================

3.1 三随机种子验证稳定性
----------------------

概率方向 v2 的最佳 validation angle MAE：

seed 20260720：0.851820°
seed 20260721：0.853291°
seed 20260722：0.630996°
均值 ± 样本标准差：0.778702° ± 0.127919°

第一版方向模型三个种子的验证角度 MAE 约为：

1.8927°、1.5497°、1.6873°，均值约 1.71°。

因此，v2 在验证集上的平均角度误差相对 v1 下降约 54%。


3.2 冻结测试：v1 与 v2 方向角误差
---------------------------------

条件                    v1 angle MAE    v2 angle MAE    相对下降
Clean                      1.901°          0.887°          53.3%
Moderate blur              1.922°          0.858°          55.4%
Severe blur                2.359°          1.001°          57.6%
Moderate perspective       2.126°          0.869°          59.1%
Severe perspective         3.603°          1.089°          69.8%
Severe blur+perspective    4.997°          1.624°          67.5%

结论：v2 的最大优势正好出现在目标场景——严重透视与模糊、透视联合退化。


3.3 最终读数指标为什么只小幅改善
------------------------------

条件                    v1 NMAE    v2 NMAE
Clean                   0.14863    0.14841
Severe blur             0.15528    0.15423
Severe perspective      0.17183    0.17290
Severe combined         0.22771    0.22660
RPM-10K                 0.34335    0.33250

方向角已明显变准，但最终 NMAE 的改善较小，原因不是方向模型没有效果，而是最终读数仍使用冻结
前端给出的 start_angle 和 range_angle。透视下起点/终点参考角误差会进入：

progress = (pointer_angle - start_angle) / range_angle

因此，当前端刻度参考有偏差时，1°以内的指针方向仍可能映射成较大的读数误差。现在的主要瓶颈已经
从“指针方向”转移到“方向角到刻度进度的映射”。


四、关键消融实验
================

4.1 双方向头的融合解码
--------------------

同一个完整 v2 权重，只改变推理解码方式：

条件                  直接向量头    圆周分布头    完整融合
Clean                    1.221°        1.229°        0.887°
Severe blur              1.319°        1.382°        1.001°
Severe perspective       1.370°        1.313°        1.089°
Severe combined          1.901°        1.834°        1.624°

结论：完整融合在四个条件下的方向角 MAE 均最低。直接向量头和圆周分布头不是重复设计，二者
具有互补误差。


4.2 投影配对与等变损失消融
--------------------------

所有模型使用相同数据划分、ImageNet 初始化、30 epoch、batch 24、AdamW 和随机种子。

条件                  完整模型    去等变损失    去投影配对
Clean                   0.887°        0.959°        0.840°
Severe blur             1.001°        1.170°        1.060°
Severe perspective      1.089°        1.218°        1.826°
Severe combined         1.624°        1.849°        2.630°

解释：

1. 去掉投影配对后，clean 略好，说明强透视训练存在轻微 clean 精度代价；
2. 但 severe perspective 从 1.089°恶化到 1.826°；
3. severe combined 从 1.624°恶化到 2.630°；
4. 去掉等变一致性损失也在四个条件下均变差，但幅度小于完全去掉投影配对；
5. 因此最有力的论点是“精确投影配对监督显著增强困难透视鲁棒性，等变正则提供进一步增益”，
   不能声称它在 clean 上也必然更好。

最终读数 NMAE 对这些角度差异不敏感，进一步证明当前主要瓶颈在刻度参考映射，而非方向头。

六、当前可以成立的创新点
========================

1. 面向指针表读数的概率圆周双方向表示：直接向量 + 圆周分布 + 异方差不确定性；
2. 精确变换支点与指针射线的投影配对监督，而不是标签不变的普通透视增强；
3. 投影视图之间的支点/方向等变一致性约束；
4. 掩膜表示和分割无关方向表示的互补双专家体系；
5. 透视感知的 angle-to-progress 残差校准，以及保留硬失败规则的 mask/calibrated-vector 路由；
6. 训练侧 grouped-OOF、全分母失败计分、分组 bootstrap 与来源哈希组成的可审计评测协议。

不应写成首创的部分：ResNet-18、U2Net、YOLO、Dice loss、ExtraTrees、使用公开数据集本身。


七、与同类型模型比较应如何写
============================

正文主对比建议保留：

1. Classical Geometry；
2. Original Transformer；
3. VDN 的公平重训练；
4. Ours-mask；
5. Ours-final（概率方向 + 透视感知进度校准 + 安全选择路由）。

论文的主要优势应写为：

1. 困难透视/联合退化下方向角误差显著降低；
2. 双表示显著修复真实域的无输出问题；
3. 选择性路由降低严重退化和 RPM 的平均量程误差；
4. 所有失败都进入全样本分母，不依靠只统计成功样本制造优势。

不能写为：

1. 所有条件、所有指标都达到 SOTA；
2. RPM-10K 上所有精细准确率都领先；
3. 透视增强在 clean 上也必然提升；
4. 不确定性软融合普遍优于离散路由。


八、为什么训练时 GPU 占用看起来较低
====================================

需要区分“显存占用”和“GPU utilization”。两者不是同一个指标。

8.1 显存占用低是正常现象
------------------------

当前方向模型是 ResNet-18，输入只有 256×256，正式 batch size 为 24，并启用 AMP/FP16。
训练时把原图和投影视图拼接，因此单次前向的有效图像数为 48，但模型仍然较小。

实测训练期间约占用 1.87 GB / 8 GB 显存。这不代表没有使用 GPU，而是说明：

1. ResNet-18 参数和激活较小；
2. 256×256 分辨率较低；
3. AMP 将大量激活和梯度压缩到半精度；
4. batch 24 是为了三个正式种子和消融统一、稳定复现，不是显存上限。


8.2 GPU utilization 会呈锯齿状
-----------------------------

每个样本在进入 GPU 前，CPU 需要完成：

1. cv2.imread 从磁盘读取图像；
2. cv2.warpAffine 裁剪表盘；
3. 亮度、对比度、gamma、模糊、噪声增强；
4. cv2.warpPerspective 生成第二个投影视图；
5. 在 CPU 上生成两套支点热图和方向标签；
6. Windows DataLoader worker 通过 spawn 启动和传输 batch。

GPU 计算完一个小型 ResNet-18 batch 后，可能等待 CPU 准备下一批，因此瞬时利用率会从高值掉到
低值。nvidia-smi 默认显示某个采样时刻，不是整轮平均值，恰好在数据准备间隙查看会感觉占用很低。

本轮实际监控到的训练 GPU utilization 通常约为 74%～83%，显存约 1.87 GB；评估阶段只有单视图
前向且包含逐图 OpenCV 退化与 JSONL 写盘，利用率更容易降低到约 30%～40%。训练完成后 GPU 为
0% 是正常的。


8.3 当前最可能的瓶颈
--------------------

1. 在线 OpenCV 解码和双视图增强；
2. 机械硬盘/普通 SSD 的大量小文件随机读取；
3. workers=4 对 RTX 4060 的供给可能不足；
4. 小模型和较小 batch 使单个 GPU kernel 很短；
5. 每轮验证、checkpoint 保存和 JSON summary 原子写入期间 GPU 会空闲。


8.4 可做的安全加速
------------------

在不改变算法结论前提下，建议先做吞吐基准，再采用：

1. 将 batch size 从 24 逐级测试到 32、48 或 64；
2. 将 workers 从 4 测试到 6 或 8；
3. 增加 DataLoader prefetch_factor；
4. 将已裁剪的基础表盘缓存到快速 SSD，减少每轮 cv2.imread 和 warpAffine；
5. 使用 channels_last；
6. 在环境稳定后测试 torch.compile；
7. 记录 images/s、data wait time、峰值显存和整轮平均利用率，而不是只看一次 nvidia-smi。

这些改动必须先做等价性验证。正式论文实验若改变 batch size，应重新跑完整对照，不能把不同训练
预算的结果直接混在同一消融表中。


九、下一步模型改进方向
======================

当前最值得做的不是继续堆叠方向头，而是改进刻度进度映射：

第一优先级：透视感知的角度—进度校准
----------------------------------

1. 保留当前高精度概率方向头；
2. 使用 pointer angle、start angle、range angle、reference branch、透视/椭圆代理量、方向不确定性
   和分支分歧；
3. 在 SyncG train grouped-OOF 上学习小型、单调或受约束的 progress residual；
4. 输出校正后 progress 及其不确定性；
5. 只有校正风险低于原公式时才应用，保留安全回退。

原因：当前角度 MAE 已下降 53%～70%，但最终 NMAE 只小幅变化，明确说明读数映射是新的主瓶颈。

第二优先级：联合参考点/支点几何
------------------------------

让模型同时预测支点、指针方向以及刻度起止锚点，或利用预测支点重新计算参考角，使起点、终点和
指针在同一透视坐标系内估计，降低冻结前端参考误差。

第三优先级：提高训练吞吐
------------------------

先增加可复现的吞吐 benchmark，再决定 batch/workers/cache/channels_last 的组合；训练加速本身不
作为算法创新，但可以降低三种子和完整消融的成本。


十、当前阶段结论
================

1. 概率圆周方向模型已完成三种子训练、冻结测试和关键训练消融；
2. 对 severe perspective 和 severe combined 的方向角误差提升非常明确；
3. 精确投影配对监督是困难透视鲁棒性的主要来源，等变正则提供较小但一致的进一步提升；
4. 不确定性选择路由在严重联合退化上显著优于旧质量路由；
5. RPM 平均 NMAE 有进一步改善趋势，但组数少且 Acc@2% 仍低，必须克制表述；
6. 最终读数的下一主瓶颈是刻度参考与 angle-to-progress 映射；
7. GPU 显存占用低主要源于模型小、输入小和 AMP，利用率波动主要源于 CPU OpenCV 数据管线；
8. 本轮随后已实现训练侧无泄漏的透视感知进度校准，正式结果见第十一节；后续可单独做 GPU
   吞吐基准。


十一、2026-07-23 继续改进：透视感知进度校准
==========================================

上述“第一优先级”已继续实现并完成训练侧 OOF 与七条件冻结评估。

11.1 新增模块
-------------

在概率方向头之后增加轻量 progress residual calibrator。它不重新推理图像，而是使用：

1. 原始 vector progress；
2. pointer/start angle 的 sin/cos 周期表示；
3. range angle 与参考点分支；
4. 表盘框宽高比；
5. 角度标准差、圆周熵、resultant length；
6. 支点峰值、空间熵、top-2 margin 和支点位置。

校准器只在 SyncG/train 的分组 OOF 预测上学习：

target residual = ground_truth_progress - raw_vector_progress
calibrated progress = clip(raw progress + clipped predicted residual, 0, 1)

校正幅度上限只从训练 OOF 候选中选择，最终为 0.30；测试集和 RPM 标签不参与选择。

随后新增第二层选择路由，在 base mask 与 calibrated vector 之间预测收益。硬失败规则保持不变：

1. base 失败、calibrated vector 成功：使用 calibrated vector；
2. 两者都失败：保持失败；
3. 两者都成功：只有预测收益超过训练侧 OOF 阈值时才切换。

11.4 新结论
-----------

本轮实验证实此前的瓶颈判断：概率方向头已经显著降低角度误差，继续改善 angle-to-progress 映射
能够把方向精度真正转化为端到端 NMAE 与 Acc@2% 提升。

论文的完整技术链现在可以概括为：

概率圆周方向估计
→ 精确投影配对监督与等变正则
→ 透视感知的角度—进度残差校准
→ mask/calibrated-vector 防泄漏选择路由
→ 全分母失败计分与分组统计验证

需要保留的边界：

1. 进度校准和路由的模型类型 ExtraTrees 本身不是首创；
2. 创新性来自周期方向表示、投影几何监督、校准目标和安全路由的组合；
3. 严重透视和严重联合退化下，单独 calibrated vector 的 NMAE 略优于最终路由，说明路由仍有
   约 0.0002～0.0006 的改进空间；
4. 当前 SyncG test 与 RPM 已参与多轮支持性诊断，正式投稿若要求严格 confirmatory test，应增加
   未参与方法开发的现场留出集。


十二、2026-07-23 新测试集前冻结：参考分支感知的安全校准
========================================================

12.1 为什么还要修改
-------------------

对旧校准器的 SyncG/train grouped-OOF 误差按参考点状态分层后发现：

1. `start_and_end` 分支原始 vector 的 Acc@2% 已达到 0.87552；
2. 旧全局残差校准虽能修复大误差，却把该分支 Acc@2% 降到约 0.65975；
3. `default_start_end`、`start_only` 和 `end_only` 分支仍明显受益于大幅校正。

因此问题不是“校准是否有效”，而是不同参考几何状态不应共用同一个校正风险策略。

12.2 新方法
-----------

新候选方法命名为 reference-conditioned safe progress calibration：

1. 按 `default_start_end / end_only / start_and_end / start_only` 分别拟合 progress
   residual ExtraTrees；
2. 保留一个全局 residual 模型作为未知/数据不足分支的回退；
3. 每个分支独立选择 correction clip；
4. 每个分支独立选择 deadband；当 `abs(predicted residual) < deadband` 时不校正；
5. 外层验证组的 clip/deadband 只由外层训练部分内部的 5 折 grouped-OOF 决定；
6. 最终 mask/vector 路由阈值也在每个外层训练部分内部重新交叉拟合选择。

运行时只读取图像预测产生的角度、进度、参考分支、表盘框和不确定性，不读取真值、样本 ID、
数据集名或模糊/透视标签。SyncG test、RPM 和待准备的现场新测试集使用数均为 0。

---------------------------

`start_and_end` 分支在完整方法下只对约 8.5% 的成功样本执行校正：

原始 vector：NMAE 0.06420，Acc@2% 0.87552

也就是说，新方法仍修复了少量大误差，因此平均误差下降；同时保留了大多数原始高精度
结果，Acc@2% 只比完全不校正低约 1.14 个百分点，远好于旧全局校准对该分支的扰动。

12.5 论文中可写的新增贡献与边界
--------------------------------

可写：

1. 参考几何状态条件化的角度—进度残差建模；
2. 由训练侧嵌套 OOF 选择的分支安全死区，使模型能够“拒绝不必要的校正”；
3. 同一外层折内的全局、分支、共享死区和分支死区消融；
4. 校准器与路由器模型、训练输入和源码 SHA-256 绑定的冻结评估。

不可写：

1. ExtraTrees 或 deadband 机制本身是首创；
2. 新方法已经在未见现场数据上确认提升；
3. 训练侧 OOF 提升可以代替独立测试集结果；
4. 所有分支的所有指标都同时改善。

正式结论必须等新的现场留出集准备后，用冻结模型只跑一次。当前已经提供
`experiments.evaluate_reference_conditioned_pipeline`，届时不再修改模型、clip、deadband
或路由阈值。

13.4 结论边界
-------------

这项结果补足了真实公开数据上的方向对比，可以支持“真实低质量单指针方向泛化优于同协议

也没有可核验的透视角标签，因此异常视角结论仍由 SyncG 固定单应退化实验支持。
