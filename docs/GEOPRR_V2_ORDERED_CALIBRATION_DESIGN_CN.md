# 全局有序刻度坐标图：严重误读的结构改进方案

状态：未训练、未验证的新表示候选。原三臂各65轮及全部评估已完成，组合组未通过冻结源验证门槛，不扩种子；完整结果见[三臂实验记录](data/geoprr_v2_compositional_20261020/README.md)。本说明不授权启动新GPU训练，也不将GT几何诊断写成新模型成绩。

## 研究问题

低支持并不必然表示指针无法定位。固定三个源验证样本的组件诊断发现，`sync_3663`的一致性模型有98.96%的Q落在真实支持内，但预测M在读出点附近出现局部缺口；正确Q/M下的预测U仍在量程两端形成双峰。强制原场的误差约59.995%FS，比direct回退的44.822%FS还差。因此，仅删除fallback或降低阈值不能解决这条失效链。

另一个样本`sync_12540`的支持量充足，却因U在正确位置饱和到0而误读。这里共同的问题是：逐像素自由预测的U/M没有保证它们属于同一个全局标定坐标系统。完整数据与oracle反例见[低支持组件诊断](data/geoprr_v2_low_support_20261020/README.md)。

## 核心方法

将自由U/M替换成一个由神经网络预测的全局有序刻度坐标图。所有刻度射线共享标定中心，沿物理读数顺序严格单调；每个位置的读数由它在相邻刻度射线之间的位置决定。原Q仍预测表盘平面上的虚拟指针读出点，最终在同一个坐标图上读取Q。

```text
单张RGB ROI → 原MobileNetV4与FPN ┬→ 原Q头：虚拟指针点分布
                              └→ 小标定头：共享中心与有序刻度射线
                                           ↓
                           全局刻度坐标图作用于Q → 归一化读数
```

主贡献候选是标定表示的结构约束，不是新增loss、homography计算或概率期望公式。旧U/M/direct头在新候选中被替换，不新增encoder、专家或路由。当前在跑的第三组不采用此改动。

## 可实现表示

固定65个进度锚点`s_j=j/64`。一个空间标定头输出：

- 归一化ROI中的标定中心`c=(cx,cy)`；
- 起始射线的二维方向`z0`；
- 有符号总弧长`L=2π tanh(l)`，支持顺/逆时针；
- 64个间距logits。

在间距单纯形上定义`g_j=ε/64+(1−ε)softmax(v)_j`，令`a_j`为g的累计和、`a_0=0`，得到`φ_j=φ_0+L a_j`。ε是整个弧的固定最小间距预算，初版取0.001；真正实现前须用源训练生成的几何目标确认该下界不排除合法标定，不能丢弃违规布局或按验证难例调值。所有射线都通过同一个c，顺序由参数化保证。该头可用保留空间布局的8×8 FPN池化特征和一个小MLP实现，原Q头复用。

每个输出像素计算相对c的方位角，围绕刻度弧中点展开；按L的方向转换成递增坐标，在相邻`φ_j`之间逆插值得到进度`s_A(x)`。同一射线上的所有半径共享同一进度，不存在独立M在正确点局部置零的操作，也不存在每个像素各自任意放置0/1双峰的U分布。

间距下界保证的是数值非重合，仍须报告最小角间距和逆插值条件数，不能把非零当作稳定。

这一结构保证共点、有序及弧内连续；它不保证任意预测射线图都能由同一单应矩阵生成，也不保证网络预测天然具备射影等变性。它比完整H-angle模型更灵活，而这也可能增加估计误差。

## 监督、输入与读出

训练标签由原有源训练H、有序刻度与角度标签生成：将65个canonical虚拟刻度点以及canonical圆心投影到ROI，得到中心与有序射线。标定中心是表盘平面圆心，不偷换为高于表盘的可见针轴原点。推理只用RGB，不输入GT H、刻度点或mask。

几何坐标契约固定为：192网格`(i,j)`对应768 ROI像素中心`(4(j+.5)−.5,4(i+.5)−.5)`，归一化坐标为`(2(j+.5)/192−1,2(i+.5)/192−1)`。GT投影中心和刻度点使用同一half-pixel归一化；方向由刻度点减标定中心后归一化得到。监督生成后的中心和有向单位射线，不回归具有整体尺度或偏移gauge的原始间距logits。

最小首筛冻结同一已完成普通监督checkpoint的encoder/FPN/Q，仅拟合小标定头。几何目标固定为归一化中心L1均值与65个有向单位射线的L1均值之和，两项等权，替换旧U/M监督，不增加一致性或mass辅助项。读数只用于源验证，不让标定头依读数损失学习补偿Q尾部。固定特征可缓存以减少重复骨干前向。该拟合尚未执行。

主读出预设为：

`y_hat = Σ_x Q(x) s_A(x)`。

需要读数分布时才将`s_A(x)`的质量送到相邻bin；再取期望与上式等价。没有`ΣQM`分母和低支持direct切换。弧外Q按固定规则夹到端点并逐图报告其质量，不能为某个样本选择接缝。中心、起始方向或弧长退化、非有限及几何无定义均保留该行并计失败误差1，不通过换专家或删行提高成绩。中心邻域的数值规则需明确允许softmax Q的微小正尾部，不能以“任意非零中心质量”判整行失败；容差在纯数值/源训练协议中固定，逐图输出中心邻域Q质量，不按验证难例选择。

## 已完成的表示检查

复用三个布局的GT几何及六张保存Q，不做新模型前向，65个投影锚点均严格有序。GT支持内最大坐标插值误差分别为0.000243、0.000122和约5.1e-9%FS。这只验证三个布局上的表示精度，不代表RGB网络能预测同样准确的坐标图。

GT坐标图也保留负例：普通监督`sync_3663`的误差为4.19253%FS，比其原CPU场读出的2.37855%FS更差。该图有约22.12%的Q被夹到首端；Q尾部不会因标定表示改变而自动消失。image-angle与canonical-angle在弧外的端点选择差异已与弧内插值误差分开记录。

## 最小验证与停止条件

1. 先检验表示空间。在完整1506源验证、同一冻结Q上比较GT坐标图oracle、原native/固定r8与后续预测坐标图，全部失败留分母。GT oracle没有整体改善空间时，不训练新头；有空间时才考虑同seed的小头拟合。主指标为NMAE、>2/>5、tail10、最大误差及失败数，同时报告中心/射线误差与首尾夹断质量。三个指定样本不能作为方法主结果。
2. 再检验结构必要性。比较三种小头，均使用同一冻结backbone/FPN/Q、同一个8×8布局特征及相同MLP隐藏层、源图像与更新预算，并按相同中心/有向射线目标监督：新有序坐标图；独立预测63个内部归一化刻度位置、再以固定端点的单调投影恢复顺序的同类头；最小H-angle头。后者预测标定中心、共同规范的2×2射线变换A及canonical弧长，生成`normalize(A^{-1}[cos(αs_j),sin(αs_j)])`作为射线，不强迫它额外回归与角度无关的H第三行。独立头的后投影采用与新结构相同的最小间距约束，不能故意让无序输出无定义来削弱对照。各头实际参数量与监督/优化预算须单独列出；几何失败都保留在完整分母。这个对照不单独声称证明“共点”的独立效应，主要检验全局坐标表示及按构造有序相对普通几何头/后投影的增益。同一标定图上的全Q与点估计仅作读出对照；如果换decoder或简单投影已复制收益，不将其包装成新表示贡献。

当前没有启动这两项实验。用户已禁止扩种子；不安排大矩阵或追加loss扫参。若预测图不优于强普通监督，或增加严重误读/尾部/几何失败，则停止这一候选的训练扩展。

## 论文论点与近邻

[Howells等CVPRW2021](https://www.jjcvision.com/projects/gauge_reading.html)已有透视校正、标定/指针点和角度读取，[WACV2024](https://openaccess.thecvf.com/content/WACV2024/html/Leon-Alcazar_Learning_to_Read_Analog_Gauges_from_Synthetic_Data_WACV_2024_paper.html)已有合成结构监督。因此，使用几何、换轻骨干或读取角度本身均不是新颖性。全局鲁棒拟合也是成熟工具，例如[DSAC](https://openaccess.thecvf.com/content_cvpr_2017/html/Brachmann_DSAC_-_Differentiable_CVPR_2017_paper.html)，不能把它改名当作主贡献。

本方案可检验的研究论点是：用一个全局有序刻度坐标图限制标定函数的可表示空间，能否在相同局部定位证据下，减少自由U/M特有的局部洞、端点双峰和错误回退。只有预测图的完整结果和最小结构对照支持这一点，才构成论文方法证据；目前尚未建立。

## Limitations

中心、起点、方向或弧长整体预测错误仍可能造成系统误读；严格顺序不等于正确顺序。65个锚点的表示只在三个GT布局上做了数值检查，极端透视和插值误差尚未全体验证。弧外截断和Q尾部可能使正确标定下的任务误差反而增加。确定性标定图不提供校准后的几何不确定性。当前任务限于单指针ROI和归一化进度，不能据此声称解决OCR、量程识别、多指针、镜头畸变或真实域迁移。新标定头的参数、FLOPs、精度及完整成本须实测，不能把输出表示缩减写成整网加速比例。没有新模型成绩、独立查新认证或论文发表保证。
