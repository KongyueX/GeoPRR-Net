# MobileNetV4网络特化：有序坐标中的局部证据读数头

当前最佳已完成模型是保留原结构的普通监督重训MobileNetV4，seed20262020，训练65轮、best63，参数7,695,954。新读数头已实现并完成表示与接口检查，尚未训练，也没有新的RGB准确率结果。

## 当前模型与实际阻断

同一1506张源验证图上的结果如下，误差均为%FS。

| 模型／读数方式 | NMAE | >2／>5 | 最坏151张均值 | 最大误差 |
|---|---:|---:|---:|---:|
| 最初MobileNetV4，native | 0.191749420 | 7／5 | 1.204454 | 32.006876 |
| 普通监督重训，native | 0.147924067 | 5／3 | 0.897473 | 26.627396 |

普通监督重训沿用原模型结构和单图监督，使用增加的源训练数据及更多曝光，未启用新增state一致性／组合损失。其收益不能归给新算法。固定r8是在同一256-bin读数分布的最高峰两侧各8个bin内重新归一化求期望，与native使用完全相同的权重。

## 一个具体结构候选

保留MobileNetV4与FPN，把独立Q／自由U／M及其门槛读数替换成一个统一的候选证据算子：

```text
RGB ROI → MobileNetV4／FPN
                  ├→ 全局上下文 → 六参数有序进度坐标
                  └→ 高分辨率特征 → 按256个进度候选分别查询16个径向位置
                                      → 共享位置核 → 256-bin分布 → 读数
```

六个参数为中心c的两个分量、方向φ、伸缩s、剪切h和跨度α。定义

`B = Rφ [[exp(s), h], [0, exp(−s)]]`，`α = 2π sigmoid(a)`。

进度q_k=k/255对应图像方向

`v_k = normalize(B⁻¹ [cos(αq_k), sin(αq_k)])`。

令t_k为该射线从c到ROI边界的距离，查询位置为

`x_kj = c + (j/17)t_k v_k`，j=1…16。

一个共享的16×64位置核读取FPN特征：

`s_k = Σ_j w_jᵀ F₄(x_kj)/16`，`p_k = softmax(s)_k`，`reading = Σ_k p_k k/255`。

所有候选由同一个有序坐标生成。网络需要让候选读数得到多处图像特征的共同支持，输出完整256-bin分布。它直接改变网络的表示和读数运算，不依赖新增loss堆叠。

该结构使用虚拟盘面坐标查询特征。虚拟Q点与物理针尖有不同语义；这里没有把查询射线当作物理针体路径，也没有针根与盘面中心同高的假设。

## 已完成的最小检查

在既有1506个教师场上，用原H／跨度／ID缓存解析分解上述坐标族，没有加载Q、目标读数、RGB或网络权重。全部1506的教师坐标可被该六参数正行列式族表示：

- 全部中心位于开放ROI单位方形内，全部具有相同正向约定。
- 原192×192支持网格上，最大进度场差8.88178×10⁻¹⁶。
- 最大角度差1.77636×10⁻¹⁵ rad，零接缝不一致图像。
- 无非线性优化，CPU单次处理6.299173s。

这证明教师场表达能力，没有证明RGB能预测这些参数。

独立组件原型有13,766个参数，接受F₄和192维全局上下文。三个CPU检查通过，覆盖半像素／`align_corners=False`采样、候选索引与角度对应、完整概率质量、输出形状和有限非零梯度。实际执行3次未训练组件前向、4个生成特征项及1次反传；优化更新、骨干图像前向、权重加载和GPU调用均为0。它尚未接入正式训练队列。

## 创新与验证边界

沿候选线聚合深度特征已有[Deep Hough Transform](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123540239.pdf)等先例；图像条件动态分类器也与[MaskFormer](https://proceedings.nips.cc/paper_files/paper/2021/file/950a4152c2b4aa3ad78bdd6b366cc179-Paper.pdf)、[K-Net](https://proceedings.neurips.cc/paper/2021/file/55a7cf9c71f1c9c495413f934dd1a158-Paper.pdf)接近。因此，这个可执行结构目前是特化读数头候选，不能仅凭径向采样或动态权重宣称算法级创新。

需要验证的机制是：共享标定坐标下的多位置证据，是否能同时减少标定错误与错误位置概率，并比同参数的单位置查询更好。最小结构对照保留相同上下文生成器及16×64核，只把16个查询位置重复为同一个外侧位置；参数不变，删除多位置证据。

原完整1506门槛、普通1495／1497保护、旧严重6张、无新增>1／2／5及tail／max要求保持。不得把教师表达检查、生成特征单测或冻结Q替代诊断当作新RGB成绩；也不能要求一个Q替代诊断证明尚未训练的多通道特征核有效。正式模型必须有具体标签／推理合同、匹配监督与曝光对照，并按原授权门槛推进，不能因教师场可表示就启动训练。

## Limitations

新头的标定可学习性、多位置特征是否真正有用、严重误读与普通样本保护，以及相对极坐标／Hough／可变形采样方法的核心区别均未验证。结构化坐标仍可能预测错误，分布期望仍可能落在错误模式之间。径向采样降低了一个局部计算项的运算量，但尚无整体速度结果；用户要求加快研究推进，不以理论运算比替代准确率证据。

全部模型比较均为反复查看的单seed源开发结果，未提供新官方测试或真实迁移结果，不报告跨seed标准差。
