# MobileNetV4 细结构读出与可靠性路由对比

## 目标与固定协议

在共享 MobileNetV4 下修复直接分支的饱和常数预测，增强指针细结构定位，并检验独立直接读数与几何场读数之间的可靠性选择。成功证据同时包括平均精度、超过 2%/5%FS 的误读数量、尾部误差与执行成本，不预设双专家获胜。

训练种子固定为 `20262020、20262021、20262022`。复用现有 14,494 张源训练、1,506 张源验证及 4,000 张官方测试名单，不重新划分源训练与验证。768 输入、192 结构输出、256 读数格、batch 32、65 轮（5 轮骨干冻结、60 轮联合优化）、原学习率与增强保持一致。只使用现有独立 `.venv`。

源验证 NMAE 用于选检查点；测试图像和真实域不能用于学习路由器或选择超参数。官方测试已经在历史开发中被查看，本轮属于已有测试集上的探索性比较，不能称为新建立的盲测。

## 既有直接分支诊断

旧 MobileNetV4 最佳检查点在 64 张固定源训练图上全部选择 bin 131，读数标准差 3.61e-8，最大概率至少 0.999999642。按检查点 AMP scale 还原后，原 L1/CDF 的输出层权重梯度范数为 6.46e-8，two-hot 交叉熵为 27.70；参数确实在优化器中。修复针对的是已实测的分布饱和，而非遗漏参数。新模型仍需用完整训练与源验证结果证明直接专家学会了读数。

## 模型与对照

| 配置 | 变化 | 种子 |
|---|---|---|
| baseline | 原 MobileNetV4 场模型；保留既有损失 | 三个；20262020 复用已完成模型 |
| global_ce | 原结构增加稳定的 two-hot 交叉熵，保留连续损失 | 20262020 |
| spatial_ce | 多尺度位置感知空间池化的直接专家，独立于 U/Q/M | 20262020 |
| detail_ce | spatial_ce 加 stride16 粗定位与 stride4 细定位残差 | 三个，主配置 |
| raw_spatial | 相同空间直接头，独立训练，无结构标签或几何分支 | 三个 |
| multitask | 与主配置相同结构监督，以直接头读数 | 三个 |
| dynamic | 主配置的两级低分辨率解码器采用动态卷积 | 20262020，探索 |
| wide | 原全局读数路径加宽解码器，交叉熵监督 | 20262020，容量对照 |

主配置的两个读数专家均有独立监督，不能靠路由权重关闭某个专家的训练。直接读数头用 RGB 多尺度特征与位置坐标，不读取几何场预测。细定位仅细化虚拟表盘读出点 Q，仍使用已核验的物理标签，不能将可见针尖当作同一对象。

完整参数量实测为：主配置 7,919,575，wide 7,928,850（仅差约 0.12%），dynamic 8,141,279，独立直接读数器 7,600,212。路由 MLP 参数另计。动态卷积只在低分辨率解码器使用四个卷积核的输入相关组合，不能称为复制了四个完整骨干，也不能从参数量推断部署速度。

## 三折路由训练

在原 14,494 张训练图内部按完整场景划分三折，折划分种子固定为 20262020，并在三个模型训练种子之间复用。每个折模型只用另外两折训练，用原源验证集选检查点，在未用于拟合或选模的留出折生成预测。合并三个留出折，得到覆盖原训练集的 OOF 专家预测。

小型路由 MLP 从预测分布统计、几何支持、专家分歧和共享图像特征预测两个专家的绝对误差风险，目标单位为 %FS。路由训练只用源训练 OOF 缓存，以完整源验证集的硬选择 NMAE 早停。最终使用在全部 14,494 张训练图上训练的主读数器。几何无效时使用直接专家；其他情况选择预测风险较低的专家完整分布。该设计需要计算两个轻量头，不宣称稀疏执行节省。

每个种子评估场读数、直接专家、固定均值和学习路由四种输出。固定均值不做测试集权重调参；带真实标签的逐图择优不得作为正式模型结果。

## 执行与恢复

```bash
cd /root/autodl-tmp/geoprrnet/code
source experiments/geoprr_v2_env.sh
python -m experiments.run_geoprr_v2_optimization
```

输出位于 `/root/autodl-tmp/geoprrnet/runs/geoprr_v2_optimization/`：

- `queue_state.json` 保存当前步骤、PID、日志、退出码和已完成步骤。
- `manifests/` 保存三折训练与留出身份，不覆盖原名单。
- `readers/`、`caches/`、`routers/` 保存模型、OOF 预测与路由器。
- `evaluation/` 保存完整逐图测试预测；`exports/` 保存汇总。

单卡顺序执行，失败会停止并记录实际日志，不在缺失折模型时继续训练路由器。重复执行同一命令会跳过已完成步骤、从相同配置的 latest.pt 恢复未完成读数器。未结束的训练进程需要先检查，不能重复启动。根据已有训练速度，约 24 个新增读数器（其中 9 个为三折模型）的总预算初估 35–45 GPU 小时；新结构速度会影响这个估计。

## 结果边界

新训练必须验证直接专家的源验证误差、输出方差和梯度恢复，不能仅凭 CE 有限就宣称修复完成。新测试的 723 个 gauge/scene 组合与历史 145 个场景别名不同，配对统计须先统一分组。旧 GeoPRR 的分辨率、源训练角色及选模方式不同，历史误差变化不能单独归因于骨干或路由器。真实域、扰动和受控因素干预仍需各自的完整评估，不用原生 SyncG 成绩替代。
