# 参考条件联合读数：单seed源开发协议

本候选保留普通监督MobileNetV4的骨干与FPN，用局部角色证据和共享参考状态替换自由U／Q／M／direct读数。核心假设是：起点、指针虚拟读数点与终点的关系应在同一个起点解释下形成联合分布，再转换成读数；先独立形成两个相对量再相乘，会丢掉共同参考带来的依赖。

这是待正式验证的网络机制，不是已取得准确率收益或已经确认的新颖性结论。原普通监督best63＋固定r8仍是当前最佳已完成RGB参照。

## 输入与角度坐标

推理只输入768×768的RGB ROI。MobileNetV4、64通道FPN与普通监督best63共享初始化。投影后stride8／16／32特征各自全局池化、拼成192维；stride4解码特征用于局部证据。

四参数上下文头给出中心c及det=1的SPD矩阵S，构成角度线束整形：

`L=[[exp(s),0],[h,exp(−s)]]`，`S=LLᵀ`。

完整圆周使用256个角度候选，每条方向查询16个固定的ROI边界相对位置。共享16×64×16径向嵌入产生角色匹配token。查询位置属于图像特征坐标，不能当作真实针体路径。

既有教师角度映射的正行列式部分可写为`A/√det(A)=Rφ S`。S去除对称角度畸变，剩余共同旋转只改变绝对phase；读数关系层消去这个共同phase。四参数不恢复完整射影半径或非共面针体几何。

## 参考条件关系层

角色token通过共享权重的unary与内容双线性匹配，形成：

- `A(a)`：起点候选分布；
- `P(p|a)`：给定起点解释的虚拟读数点分布；
- `B(b|a)`：给定同一起点解释的终点分布。

没有绝对phase位置编码。将条件分布换到相对索引：

`P_rel(a,d)=P(a+d|a)`，`B_rel(a,s)=B(a+s|a)`，索引均按256循环。

主候选联合状态为

`J(d,s)=Σ_a A(a) P_rel(a,d) B_rel(a,s)`。

这里的混合索引是受角色监督的起点候选a；不会额外预测自由混合组件权重。一般条件头不能套用无条件三重相关的FFT公式，实际使用矩阵乘法。

同参数control使用完全相同的条件地图，先求边缘再相乘：

`D(d)=Σ_a A(a)P_rel(a,d)`，`T(s)=Σ_a A(a)B_rel(a,s)`，`J_product=D⊗T`。

该删除引入了两个独立的起点副本，正好测试共享参考依赖。两个训练臂的参数、初始化、标签、曝光、优化与选checkpoint规则相同，只改变联合状态的生成公式。

## 完整质量读数

δ与span使用同一圆周256格，`θ_i=2πi/256`。span=0包含零跨度／完整一周的循环alias，质量均匀进入256个progress bin。其他状态先围绕span中点展开δ，再以`δ_unwrapped/span`计算进度并裁剪到[0,1]，做two-hot投影。保留全部状态质量，不使用GT空间mask、预测质量门槛、r8或direct回退。

原数据的真实跨度为60–350°，不包含完整一周。完整圆周仪表需要额外绕行身份，未由当前状态定义支持。

## 标签与固定目标

全部结构标签只在训练／离线检查中使用，由现有ROI H、刻度跨度、U／M和y派生。正向极分解得到φ后，三个虚拟角色的绝对phase为：

`start=−φ`，`pointer=−φ+span*y`，`end=−φ+span`。

pointer角色是原虚拟盘面读数点的phase，不是材料针尖；不输入GT针型、隐藏顶点身份、H、中心、角度或跨度进行推理。

固定目标为

`role_conditional_nll/(3log256) + gauge_aligned_field_l1 + progress_cdf`。

角色NLL在同一GT起点two-hot下监督条件pointer／end行。场L1用训练标签φ、span对齐预测角度坐标，再与原U在原GT支持上比较；CDF沿用既有读数目标。无loss／窗口矩阵，三项权重均固定为1。两个新臂使用相同标签和目标，不能把相对旧模型的全部收益归给联合层。

## 准入与实验顺序

G0是标签／表示与实现准入。完整1506个GT角色标签的量化读出已检查，原数值要求均满足：标签量化NMAE0.000901983%FS、最大0.148385718%FS、>1／2／5均0。输入包含GTy，不能当作RGB成绩、学习救回数或单独的训练批准。独立重建最大逐图差1.34×10⁻¹⁵。

还需同时满足：具体RGB推理／标签合同、同参数对照、实际共享权重初始化与零优化runtime检查。条件齐备后，按用户既有授权启动一个正式候选，不等于预先认定性能成功。

同一CNN前向保存参考entropy／最大概率、joint–product状态L1与另一个读出公式的诊断值；这些不参与选择checkpoint或逐图挑解。若起点近乎点质量且两种读出没有实质差别，不能把性能归给共享参考机制。

## 方法边界

[Learning to Read Analog Gauges from Synthetic Data](https://arxiv.org/html/2308.14583)已使用三个独立360-way角度头。三种语义角色、角度分类和相对读数本身不是本方案的新贡献。三重相关与共同旋转不变量也属于既有[bispectrum理论](https://arxiv.org/abs/0902.0196)，一般条件图模型求和不作新定理。待验证的差异是图像内容条件下的参考配对、共享参考的联合读数及同证据删除所证明的收益。

该模型仍假设pointer与end在给定起点／图像后条件独立。同一起点下若存在互相关联的多组pointer／end解释，仍可能产生交叉状态；错误的局部证据不会被代数自动纠正。已保留明确反例，不宣称解决所有多峰错配或证明旧mixture失败的原因。
