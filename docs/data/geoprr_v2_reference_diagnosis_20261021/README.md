## Limitations

teacher干预含GT坐标或角色信息，存在采样分布变化；即使替换某项能消除错误，也不证明一个新RGB头必然能学会该替换。当前证据支持优先检验参考权重反馈，不能证明P／B同参考条件独立在所有样本都成立，也不能把global normalization本身称为新定理。所有计分仍为单seed、反复查看的源开发人口，无新official test、真实迁移或扩seed。
