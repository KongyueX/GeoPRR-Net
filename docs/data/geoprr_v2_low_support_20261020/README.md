# 固定三个 source-validation 样本的 U/Q/M 组件诊断

`sync_3663` 的低支持回退由读出点附近的 M 缺口直接触发，同时该位置的 U 已出现端点双峰错误。Q 有小幅偏移，但仍基本落在真实支持内。改变阈值无法解决这个样本：原预测场强制条件读数比 direct 回退更差，替换 M 为 GT 也没有恢复正确读数。`sync_12540` 则是支持有效时的 U 局部饱和错误。

实现中的 `state_field_l1` 比较两个状态的 U 期望值，`state_support_l1` 比较两张 M 的像素值。它们约束相对一致，而不是绝对正确；相同期望不要求分布形状相同，两张 M 在同一区域一起偏低也可使相对差变小。原有单图 GT 监督仍然存在，所以这些是目标函数允许的相对约束局限，不能据此证明此次局部失效的训练因果。当前实证支持修复标定表示和读出接口，尚不支持把洞、饱和或双峰归因于某个已识别的优化机制。

以下全部是诊断。强制条件读数手动计算 ΣUQM / ΣQM，忽略阈值门控；每种替换的实际支持量及按原阈值判断的 valid 均完整保存在 `diagnosis.json`。原低支持实现返回的零 `field_distribution` 是无效占位，本表没有把它当作场预测。

对 `sync_3663` consistency，即使使用 GT Q 和 M，预测 U 的条件分布仍在 bin 0、255 分别放置 48.998% 和 42.482% 的质量，期望读数为 0.474200，距 GT 0.053738 很远。这是该读出位置的端点双峰错误。单独恢复 M 后支持量为 0.989627、读数为 0.530236，仍有 47.6498%FS 误差；强制原场为 59.9952%FS，甚至大于 direct 的 44.8223%FS。降低门控阈值没有从这些数值获得支持。

对 `sync_12540` consistency，原支持量为 0.72635，Q 峰值及均值位置到 GT 点的距离分别仅为 1.413 和 1.446 像素。替换 Q 或 M 都不能修复约 0 的读数；使用 GT Q/M 后，预测 U 的 bin 0 概率仍为 93.907%。只替换 U 后误差由 4.60324%FS 降至 0.36559%FS。这一反例说明仅消除低支持回退也不足以消除当前局部 U 错误。

`sync_10` 的两个模型保持正常支持和接近 GT 的场读数，是同一计算流程下的常规对照。

## GT 标定与完整 Q 的推送 oracle

只读取原 dataset 的三个样本标定元信息，复用已有 Q 图，新增模型前向为 0。对每个 192×192 网格单元中心，按 `(index+0.5)*4-0.5` 还原到 768×768 ROI 像素坐标，以原始 float64 `roi_to_canonical` 的完整齐次变换得到 canonical 坐标。三个样本网格的齐次分母均为正，故角度也可直接由 H 的前两行计算；这里仍保留齐次除法。

令 `a` 为 GT 有序刻度弧跨度，`theta=atan2(Y/W,X/W)`，使用 `theta_u=((theta-a/2+pi) mod 2pi)-pi+a/2`，再计算 `u=clip(theta_u/a,0,1)`。这会把起始刻度附近的小负角夹到 0，避免直接取 `[0,2pi)` 后误映射到 1。三个弧跨度分别为 110°、90°、200°，GT 刻度角与进度均等间距，所以弧内的 `theta_u/a` 与原标定进度一致。

将完整 Q 归一化后计算 `ΣQ*u`，保留全部尾部质量，不乘 M，不取 Q argmax，不走支持阈值或 direct。256-bin 推送分布用相邻 bin 线性分配，保证总质量和连续期望守恒。作为比较，同时计算原 GT U 和 GT M 下的 `ΣQ*Ugt*Mgt/ΣQ*Mgt`。

| 模型 | ID | GT 标定/full-Q 读数 | GT 标定/full-Q 误差 %FS | 原 GT U/GT M + pred Q 误差 %FS | 原预测 U/Q/M 强制场误差 %FS |
|---|---|---:|---:|---:|---:|
| supervised | sync_3663 | 0.09577289 | 4.20353 | 4.83110 | 2.37855 |
| consistency | sync_3663 | 0.07649483 | 2.27572 | 2.03637 | 59.99519 |
| supervised | sync_12540 | 0.05436864 | 0.78982 | 0.79002 | 1.45654 |
| consistency | sync_12540 | 0.04852048 | 0.20501 | 0.20521 | 4.60324 |
| supervised | sync_10 | 0.51167913 | 0.05131 | 0.05131 | 0.07882 |
| consistency | sync_10 | 0.51105827 | 0.11340 | 0.11340 | 0.12534 |

consistency 的两个问题样本支持继续检验由标定生成 U、完整推送 Q 的路线。supervised `sync_3663` 的 oracle 却比原预测场差，说明 Q 尾部、几何和原模型误差补偿仍会影响结果；该路线没有获得普遍优于自由 U/M 的证据。对这个 supervised 样本，完整 Q 中分别有 22.110% 和 1.539% 的质量夹到首尾端点；consistency 对应仅为 0.502% 和 0.245%。

使用 GT Q 再通过同一 GT 标定得到的三个读数分别为 0.05373994、0.04647059、0.51219236，与目标一致至网格离散误差。完整 Q 推送分布的总质量及期望守恒、三个布局的小负角映射到 0 均已进行数值检查。

## Limitations

诊断仅覆盖同一 seed 下指定的三个 source-validation 样本，不能证明全局 collapse、估计总体故障比例，或识别训练损失导致这些错误的唯一因果链。GT 组件替换使用标注几何，不能作为新方法或部署效果；Ugt 在 GT 支持区以外没有监督语义。GT 标定/full-Q 是给定预测 Q、假设标定完美时的候选性能参照，既非数学意义的误差上界，也非可部署结果；标定预测的可学习性仍未检验，H→angle 的组合本身没有建立论文新颖性。支持局部缺口、端点双峰/饱和是当前模型的实证症状，尚不能据此区分视角变换、状态变化、端点布局歧义或特定损失耦合的训练成因。全部检查未修改训练代码、配置、数据、阈值或现有训练进程，也未重报完整验证集或官方 test 成绩。

## 结构方向

主候选为全局有序刻度坐标图：共享标定中心、严格有序的射线与可微逆插值，替换自由逐像素U/M与direct切换。它是未训练方案，GT表示数值检查不是预测模型效果。具体机制、最小验证和停止条件见[设计说明](../../GEOPRR_V2_ORDERED_CALIBRATION_DESIGN_CN.md)。
