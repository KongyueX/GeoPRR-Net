# v14任务锚点与端点微调模型的固定中点：完整结果

2026-10-23。**预先固定alpha=0.5的同家族权重中点，在两个家族都改善了完整微调端点best1的源均值与源max，并保留部分相对任务锚点的两域收益；代价是两个外域均值都差于完整微调端点best1。** feedback中点源／Industrial／RF100为0.064807／17.548032／10.244465%FS、源max5.829561%FS；local中点为0.079489／21.120151／8.198358%FS、源max12.290969%FS。两个中点相对各自原任务锚点的源均值和源max仍更差，不能称全面改进。

## 本轮结论

本轮夜间迭代已形成完整可审阅结果：真实端点源覆盖在feedback和local两个原生家族都取得匹配跨域增量，同时存在源严重样本代价；固定CNN权重没有保留这些外域增量；固定中点提供了部分源／外域折中，没有全面胜出。保留全部候选、原模型和负结果，不据这些已查看外域继续扩展alpha、训练轮次或模块。全部既定队列已经完成，没有后续训练或alpha扩展排队，广泛泛化仍是开放问题。

## Limitations

固定alpha0.5来自任务训练锚点与已按源选出的端点best1，不是zero-shot foundation模型设置、输出集成或新训练结果。两外域已反复查看，属于开发人口，单seed既有模型的确定插值不构成新盲测、显著性或新算法认证。两家族历史不同，仅作家族内匹配判断；非线性读出与BN中点不保证随alpha平滑，也不保证所有严重样本改善。完整源／外域分母及原FP32 target保持一致，RF100标量来自离线四点、零位仅6张。没有新背景多样性，也未解决全部数据覆盖与跨域缺口。原14494／1506／4000、普通／严重名单、旧G1／anchor失败和配对守恒负结果保留。RGB、权重、raw run／合同、H／C／XYZ及像素只私有保存。
