## Limitations

单seed、每臂4轮，Industrial与RF100均已查看并参与开发方向选择，不能声称新盲测或统计显著性；RF100目标沿用四点离线派生标量。v9控制复用相同配方与曝光，但ROI消耗NumPy worker随机流，光度增强不是逐步相同实现。本结果否定当前强度与短训练配方的收益，不能排除所有几何增强。初始化、BN和成本以保存执行记录与实现为证，CPU核对未加载checkpoint或重新推理。原精确端点覆盖缺口、14494／1506／4000人口、旧G1／anchor失败与配对守恒负结果保持原状。RGB、权重、原run几何和private trace只私有保存。
