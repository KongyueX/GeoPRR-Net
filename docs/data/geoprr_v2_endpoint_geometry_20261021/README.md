## origin/outside和同高合同

核对的官方源为[SyncG 337b868...](https://github.com/SKYWOWDYH/SyncG/blob/337b868f0f5495b31acc383433cac44040247bf2/scripts/generate_syncg.py)，定义及规范化模板证据见[label_contract.json](label_contract.json)。

- 651–658行：origin为固定世界点(0,0,z)的投影，三模板z分别为0.04、0.05、0.025。
- 524–546行：outside为evaluated mesh顶点经world变换后，投影距归一化图像中心最远者；不保证针尖中心、针体中心线或可见性。此距离也不等于1920×1080图上的像素欧氏距离。
- 27–55行：H对应世界z=0参考平面；刻度标注高度为0.002。源整数坐标由int量化，正坐标截断为floor。

已有完成的g0000因子快照提供三模板针端高度：

| 模板 | origin z | 径向针端顶点z |
|---|---:|---|
| pointer1 | 0.040000 | 0.020382 / 0.027456 |
| pointer2 | 0.050000 | 0.022514 / 0.027563 |
| pointer3 | 0.025000 | 0.010767 / 0.014728 |

这些是原blend模板的已有快照，无新Blender运行。针只绕z旋转，因此所列高度不随状态改变。但outside按相机投影选择，表内不代表每张原始图实际选中的顶点；网格也包含近似等于origin高度的hub顶点。因此能确认的是**生成规则不约束同高，严格同高消项不能直接用于这组标签**，不能断言所有1506图的两点都不同高。

## 冻结计算合同

1. 不读取RGB、权重或dataset item；只读原validation名单、已存float64几何缓存与历史预测。
2. 用同一half-pixel source→ROI映射，分别将两点变到metric canonical，再取outside−origin。H已经是ROI→canonical，不再求逆，不把图像位移当位置变换。
3. 用与此前continuous GT-H相同的arc-midpoint展开，然后clip到[0,1]。不按当前y选择wrap、符号、窗口或阈值。
4. 与原float32 target逐图计分；另保留相对float64物理y的原始圆周方向误差、未clip进度、端点clip、原图及canonical长度。失败保留error=1和1506完整分母。
5. 端点扰动固定为±1原图像素；映射每点4角，使用asin((e_origin+e_outside)/length)/arc的保守方向界，不包含H/刻度误差。该敏感性诊断不用于删图或改变主成绩。

只有1张clip到首端、2张clip到末端。未clip的NMAE为0.166287727%FS，原始方向最大误差为1.053688679%FS，仍有同两张>1%FS；严重错误消失不依赖裁掉大误差。最短原图点距116.056px，最短canonical点距0.828877，无零位移或量化角不可辨识案例。

数值门槛在首次计算前固定为既有GeometryConfig的1%FS容差；1506图原始方向均有效，但12479和3401超过该容差。该门槛未通过，与严格同高前提未成立分别记录，没有改成2%以获得通过。

## 独立复核与成本

独立NumPy程序没有导入主评估器，重新计算全部1506图；数值列最大差1.7764e−15。另从原annotation H与刻度点，以复数最小二乘独立重建标定框架，raw progress最大差2.1095e−15。ID/group/target、指标及rescues/new全部对齐，见[independent_verification.json](independent_verification.json)。

主审计CPU wall 0.246509s，独立复算0.381342s；均为脚本内计算边界，不是整个源码核查/传输任务耗时，也不是模型推理速度。主进程峰RSS为58,224KiB。新模型前向、GPU调用、训练步数、新图读取及seed扩展均为0；GT几何诊断没有新增模型参数，基线参数仍为7,695,954。

## Limitations

这是单seed源开发集合的GT标签辅助诊断，没有新的RGB模型精度、官方test或真实域结果。已有模板快照来自固定revision的补充source；原1506逐图annotation未记录生成commit和selected vertex identity，不能冒充逐图3D追溯。二维误差小不证明同高，GT端点最大观测误差也不是理论精度下限。平均精度退化可能混合关键点量化、顶点语义、平面标定及高度差，本轮未把这些因素做可识别的因果拆分。
