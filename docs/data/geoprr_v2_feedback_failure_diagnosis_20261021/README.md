## Limitations

- GT替换是固定权重的条件可干预证据，不是新RGB成绩、性能上界或训练因果证明。
- P是虚拟盘面读数角色，不是可见物理针尖；GT角色构造包含y，不能作为推理输入。
- 同权重local A删除与product反事实不是匹配训练对照，不能据此声称反馈的全部学习收益。
- 正确邻接bin质量、熵和单角色替换不是唯一因果解释；坐标与角色的非线性交互均保留。
- 全部结果限于已反复查看的单seed源开发人口；不提供显著性、盲测、跨seed或真实迁移结论。
- 本包仅含显式允许的ID、target、读数、概率摘要、范数误差及标量成本，不包含原始PMF、几何矩阵、像素、图像或权重。
