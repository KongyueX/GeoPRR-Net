# best60完整1506张：相对状态错误与条件干预

**候选的δ预测存在典型精度损失和方向较集中的严重错误；λ预测的典型误差很小，但少量严重错误仍阻止单轴修复通过门槛。当前拟合模型几乎只使用一个混合分量，joint与边缘乘积的实际读数近乎相同。**这些是固定checkpoint的源开发诊断，不能作为新模型成绩或联合训练机制的因果证据。

[完整65轮正式负结果](../geoprr_v2_relative_state_20261021/README.md)保持不变：seed20262020、best60、NMAE **0.4533216657%FS**、>2/>5为62/21张、最大82.841316983%FS，independent按预设gate跳过。本诊断只重放一次完整1506张RGB，0训练、0优化更新、0新seed，使用相同模型、batch32、768 ROI、eval和原FP16 AMP。重放NMAE为0.453321619963%FS，逐图读数最大差2.384185791e−7（归一化），低于预先固定的1e−5；不覆盖原正式逐图成绩。

## 状态分布与混合分量

完整1506张上，δ圆周均值误差中位数0.260408°、p90为1.262219°；λ均值误差中位数0.005628°、p90为0.032901°。δ正确邻接bin质量中位数0.979358，λ为0.999997；这些典型统计不能排除少数正确状态质量极低的病例。逐图mean、argmax、期望绝对角误差、熵、resultant与分量误差均保留。

混合分量0权重在全部1506张均超过0.99，最小0.999853969、中位数0.999999881、均值0.999999338。这个checkpoint实际上近乎单分量使用；不能据此推论所有mixture、所有联合建模或一般MoE无效。缓存上的两分量分布和权重见[predicted_components.npz](predicted_components.npz)，汇总见[cached_state_findings.json](cached_state_findings.json)。这个近退化现象支持解释当前joint与边缘乘积近乎相同，不能证明训练目标、池化结构或初始化的因果责任。

[state_cohorts.json](state_cohorts.json)保存完整1506、普通1495/1497、原严重6张、每项路径全部>2/>5及分别相对native/r8新增>2/>5集合的状态统计、全部读数指标和ID。没有根据GT替换结果逐图择优拼接。

## 独立复算

独立程序只读取缓存PMF与逐图CSV，不导入模型或原读出实现，也不增加网络前向。四条路径的完整指标、1495/1497普通集合和全部rescues/new名单与保存行复算完全一致，逐图保存误差差值为0。用独立float64标量期望复算读数，相对GPU float32对65536个atom的scatter累计，joint、边缘乘积、GTδ和GTλ四者的最大归一化读数差分别为1.340747e−6、1.260712e−6、2.145823e−7和1.944974e−7，均在明确记录的5e−6数值容差内；这个容差与原best60同实现重放的1e−5合同分开记录。28个边缘argmax处于float32求和的近并列位置，对应最大PMF差仅1.304e−8，已保留近并列条目，不把它们作为模型重新运行的不稳定证据。完整精度、边界质量和状态统计差异见[independent_verification.json](independent_verification.json)。

## 固定计算合同与成本

Q沿两轴求和得到无条件边缘；边缘乘积及GT单轴替换都是外积，不进行分量条件重归一化。四项路径使用同一个冻结256×256全质量物理推送：λ=0或2π质量均匀分配至全部progress bin，弧外质量保留并固定端点clip；没有direct、r8、调窗口、择峰或质量回退。状态标签只用于计分与干预，RGB模型前向不读取它们。

## Limitations

源验证已被反复用于开发；所有诊断属于单seed源开发证据，未运行新的official test或真实冻结迁移，不能报告跨seed样本SD。GT单轴替换与已有GT双状态提供额外信息，既不可部署，也不保证构成新算法性能上界。未训练匹配independent，无法识别joint训练的机制效应；近单分量使用不确定其优化因果。当前结果定位了δ典型精度与错误方向、λ少数大错及非线性交互等可观测阻断，尚未验证能同时修复它们的RGB算法。后续正式候选须先有具体可部署合同及可证伪零训练验证，不由此自动改loss、窗口或扩seed。
