## 固定物理模型和选择规则

针体沿用已冻结的18/12/408材料索引，每个点保留自己的z，不使用同高origin/outside点对。只输入有序刻度像素、材料顶点像素及对应模板XYZ/身份；不输入GT H/C/刻度间隔/span/读数/旋转。

共同模型含16参数：H的8个自由度、弧长λ和针体7参数。刻度投影为

`H [cos(-jλ/(N−1)), sin(-jλ/(N−1)), 1]`，

材料投影为

`H [cX−sY+t_x−a_xz, sX+cY+t_y−a_yz, 1−bz]`。

优化全部刻度和材料对应的完整源像素重投影SSE，使用相同像素单位。四个固定起点为已保留的串行刻度解及0.2/0.5/0.8×2π弧长；初始化只依赖观测。选择收敛且满足完整正深度、正尺度、整单位圆在前和严格弧长范围的最终解中SSE最小者。四起点不是全局最优或唯一性证明；全部6024条起点记录均保留。

读数为`δ=−atan2(s,c)`，随后使用固定弧中点展开及δ/λ裁剪。没有r8、旧模型回退、GT翻转或按读数误差选择起点。实现的6个针对性构造通过，包括未知相机／跨度／逐高度材料、有向接口、解析Jacobian，以及低刻度残差却与材料投影矛盾的固定替代标定。

## 锁定预测后的诊断

9张新增>2错误分布在pointer1的5张和pointer2的4张，估计span为58.36–94.11°；pointer3的508张没有>1错误。错误组的刻度／材料RMSE中位数仅0.291929/0.328179px，反而低于其他1497张的0.342489/0.375646px。小重投影残差仍不足以保证读数准确。

所有样本的近等SSE起点原始读数极差最大为2.62304×10⁻⁸，说明这些错误没有被本次固定起点间的不一致直接暴露。错误组列归一化Jacobian条件数中位数240.33，其余组101.28；该数值只描述局部参数敏感性，不能当作置信区间。整数坐标量化和细针几何条件性是待检验解释，现有缓存不能把它们确定为唯一原因。

独立脚本未导入求解核，也没有重新优化，重放6018个接受起点及全1506计分。保存原始读数最大差5.01×10⁻¹²，裁剪读数最大差4.45×10⁻¹⁶；按重放SSE选择的最大超额仅2.96×10⁻¹²。审计保留**WARN**：`sync_15021:serial`这一未被选择的病态起点有保存矩阵算术误差放大；最终1506个选中起点没有该类警告。完整指标、人口、阈值ID和门槛独立复算一致。

## Limitations

本阶段使用GT点位置、正确针型和材料对应，原投影顶点没有逐图可见性／可观察ID证明；不是RGB识别、真实域迁移或可部署性能。共同最小二乘／bundle adjustment属于经典几何基线，不能作为论文核心创新。有限多起点及局部条件数不提供全局识别或校准不确定性证明；GT条件链也不是已学习模型的上界。所有比较为同一1506源验证开发，未运行新official test，没有跨seed统计。

完整CPU解码174.979339s，含输入加载、1506次共同拟合及写出，0 CNN前向、0模型更新、0新seed；不含Python导入、标注导出、计分、独立审计、归档及未来RGB观测提取。普通RGB参照参数7695954，几何求解没有学习参数。没有把该条件计时当作camera端到端速度。
