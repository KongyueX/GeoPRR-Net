# 外部评估诊断与旧GeoPRR比较

2026-10-22。当前证据主要指向新版v7 best64在外部ROI分布上的泛化不足；未发现RGB、归一化、checkpoint加载、量程或计分的具体实现错误。对固定8张源验证样本的当前入口重放，最大预测差仅0.0000298023%FS。该诊断不增加训练、模块、loss或目标调参。

## 与已有模型比较

以下取旧结果的clean、新结果的native，均为source-only、seed20262020，完整失败分母保留。NMAE单位%FS，越低越好。

| 模型 | Industrial-1395 | RF100-151 |
|---|---:|---:|
| 旧GeoPRR，official fulltrain main | **11.643618** | 6.607079 |
| 旧Shared full GeoPRR | 13.027493 | **3.182716** |
| Raw EfficientNet-B0 | 13.076796 | 3.214947 |
| 新v7 best64 | 21.226570 | 12.691067 |

新best64相对旧GeoPRR的平均误差分别增加9.582952和6.083988个百分点，相对增加82.30%和92.08%。统一FP32 target重新计分后结论不变：Industrial逐图448张更好、947张更差；RF100为58张更好、93张更差。旧GeoPRR三个既有seed的clean NMAE均低于新best64；旧三seed均值分别为10.950806和6.052350%FS，新模型没有新增seed。

Industrial分层结果说明退化并不均匀：

| 子集 | 张数 | 旧GeoPRR | 新best64 |
|---|---:|---:|---:|
| Test-A | 434 | 11.535696 | 21.123774 |
| Test-B | 814 | 9.878295 | 21.789570 |
| External-ROI | 147 | 21.737567 | **18.412497** |

External-ROI均值改善，但其max与尾部仍恶化。上述source-only比较不混入目标监督OOF、预测ensemble或标注辅助诊断。

## 输入与执行核对

- 新版源验证与外部评估共用OpenCV BGR→RGB、FP32除255、ImageNet归一化、LINEAR直接缩放768、eval、原checkpoint AMP及FP32头。原生读数及计分函数一致，未把GT H、center、起止方向或针尖送入模型。
- 物理量程与normalized_progress逐行一致；FP32转换、零标签、绝对误差及完整分母已核对。Industrial的588个零标签没有truthiness或offset错误。
- 严格加载原RoleTriangleReader、best64、seed20262020、7,461,316参数。当前入口重放预先固定的8张源验证图，1次CNN调用／8张图、0反传／0更新，最大归一化预测差2.98023224×10⁻7，目标全部一致。该检查是运行时重放，不是新的准确率估计。
- 旧GeoPRR按其训练方式将原生ROI缩放256，降采样用AREA；新版沿用自身训练方式缩放768。两个模型各自的预处理不同，不等于新版评估接错。未把旧处理直接套给新版。

源域与外部的裁剪分布存在实际差异：源训练／验证由标注dial_bbox裁剪；外部使用完整既有ROI，无第二次GT裁剪。源验证宽高比约0.999–1.113，Industrial为0.341–2.925，RF100为0.716–1.364；Industrial原生宽度中位数356，源验证为591。源域较紧、近正方形的裁剪与外部更低分辨率、更不规则的ROI构成合理的域偏移解释，但尚不能量化各因素的独立贡献。

## 典型失败

读取7张原生ROI，仅用于观察，图像留private。误差为%FS；Industrial采用旧公开别名。

| 样本 | 旧误差 | 新误差 | 观察 |
|---|---:|---:|---|
| industrial_000327 | 4.1940 | 99.3378 | 零位长针清楚可见，含反光与配重；新版读到接近满量程 |
| industrial_000580 | 13.4582 | 91.6726 | 明显偏暗、低对比；新版退化更严重 |
| industrial_001387 | 26.5794 | 72.3016 | 彩色盘面模糊、噪声与遮挡，两版均不准确 |
| rf100_test_000023 | 1.6530 | 86.1097 | 清晰近零仪表，新版目标3.30%FS却读为89.41%FS |
| rf100_test_000088 | 12.6656 | 69.8932 | 斜视、多圈刻度、水印、粗配重；两版均有误差 |
| rf100_test_000071 | 0.1824 | 0.1576 | 与RF23同一仪表组的中间位置，新旧均准确 |
| industrial_000072 | 3.7405 | 0.0003 | 零位斜视、反光的准确对照；不是所有零位都失败 |

RF23与同组RF71的对照，以及清晰零位的Industrial327，提示新版存在零端／参考弧位置相关的错误，不只是图像质量下降。RF23和Industrial327的outside_arc_mass分别约0.881与0.996，原读出会将弧外状态运输到端点，符合近零被读成近满量程的症状；但准确的Industrial72也有约0.594的弧外质量，因此该标量不能单独判定失败，亦不能据此锁定哪个虚拟角色或整流器出错。

保存输出还表明，使用同一联合分布边缘积的反事实读数，Industrial／RF100 NMAE为24.108655／12.913737%FS，均未优于原生21.226570／12.691067。这是既有输出的离线描述，不能把整个退化简单归因于保留联合关联，也不是新增消融训练。

## 当前模型判断

关注目前已测的外部泛化，旧GeoPRR在Industrial更合适；RF100上Shared full与Raw EfficientNet-B0更强，不能宣布单一模型在两套数据均最优。新版v7 best64不宜替代旧GeoPRR作为综合最优。v8 global best2仅在反复查看的源开发1506平均误差上略优，其外部表现未测；不能由源开发排名推断外部排名。配对守恒的匹配增量仍不成立，不恢复为主贡献。

## Limitations

人口、group、标签已按公开别名规则逐行对齐；当前组件manifest与ROI索引支持相同原生ROI来源，但历史fulltrain实际执行输入manifest缺失，尚未完成历史像素级同一性复核。当前项目也没有旧完整GeoPRR pipeline权重，不能在当前ROI上重放旧模型补齐该证据；因此这些是人口匹配、ROI来源一致的历史预测比较，不冒充一次新执行的严格同像素对照。历史数据已有开发可见性，训练人口／预算和模型配方也不同；不将结果归因于某一个结构，不报告新显著性或盲测结论。8张重放排除广泛运行时失配，不能鉴别所有局部数值情形。没有扩seed、训练、目标适配或新模块。
