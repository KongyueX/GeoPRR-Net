# 量化观测的有限反例与读数集合的贡献边界

固定60°短弧构造中，两组合法针体／未知相机解释具有**完全相同的19个整数点观测**，读数却相差**5.305858%FS**。独立重放核实了每个点的两个像素坐标、真实正深度投影和相机物理性。因此，仅凭这些整数点，任何单值读数器在这两个解释中至少有一个误差不低于**2.652929%FS**。继续把同一批点拟合得更稳定，不能消除这个信息缺口。

## 三个预先固定的构造

每个构造均使用12个逐高度材料点；三个高度层分别保留，没有把不同高度点强行放到同一平面。参考观测由明确的透视相机生成，再对连续源像素作floor量化。替代解释允许未知相机内参变化，和本次检查的未知标定模型一致。

| 固定构造 | 刻度数 | 两个解释完全相同的点数 | 读数间隔 %FS | 由该对解释给出的最坏误差下界 %FS |
|---|---:|---:|---:|---:|
| 横向充分材料，180°弧 | 20 | 32 / 32 | 0.496756548 | 0.248378274 |
| 细长材料，180°弧 | 20 | 32 / 32 | 1.050004561 | 0.525002281 |
| 横向充分材料，60°短弧 | 7 | 19 / 19 | **5.305857569** | **2.652928784** |

每个构造只执行两个确定性的有界SLSQP读数极值搜索，每个上限200次迭代，无随机重启。共6次搜索均在11–23次迭代内收敛，没有观察结果后扩大搜索预算。表中间隔取自已经保存的有效极值，提取过程没有新增优化。

若相同观测的两种真实读数为r₁、r₂，任何确定性输出a都满足

`max(|a−r₁|, |a−r₂|) ≥ |r₁−r₂| / 2`。

这只是三角不等式给出的有限反例结论。细长构造的1.05%FS间隔不足以单独否定1%FS误差保证；横向充分构造没有搜到更大间隔，也不构成全局可辨识或误差上界。

独立脚本没有调用求解核或优化器，重放每个构造的参考与两个搜索端点，共9个解释。最大像素重放差为2.274×10⁻¹³px，所有floor单元一致；同时检查完整圆在前、材料正尺度、逐点正深度、相机矩阵非奇异、正焦距和proper rotation，结果PASS。

## 原标注的量化和可观察语义

既有固定源`337b868f0f5495b31acc383433cac44040247bf2`对长刻度参考点和全部针体网格顶点使用`int`转换，即向零截断。对非负连续像素，整数k对应单元`[k,k+1)`，所以此前的`k+0.5`是单元中点，并不等于真实亚像素位置，也不证明量化误差独立、均匀或无偏。

原发布标注没有逐图生成revision。固定源语义与每张旧图的精确生成语义必须分开，不能直接将这一条件量化模型升级为全1506张的覆盖证书。

可观察身份也有实质差别：针体列表是全部网格顶点的投影，没有可见性或遮挡筛选；有序长刻度点是显式内移的3D参考点，不是统一定义的可见立方体中心。某些刻度摆放分支还有不同的径向偏移。因此，下一网络不能把隐藏网格ID或这些参考点直接当作已证明可见的RGB关键点。

## 查新结论与下一门槛

定向阅读6篇原始论文后，通用的“局部不确定性→几何可行集→任务坐标外界→保护原预测”已有强先例。关键点集合传播见[Yang与Pavone，CVPR 2023](https://arxiv.org/html/2303.12246)；集合的选定坐标外逼近见[Tang等，L4DC 2024](https://proceedings.mlr.press/v242/tang24a/tang24a.pdf)；未知量的更紧几何外界见[SLUE，TRO 2026](https://arxiv.org/html/2511.21666)。将监督预测投影到包含真值的凸集合以保护精度，也已有[SAFER，AAAI 2017](https://ojs.aaai.org/index.php/AAAI/article/download/10856/10715)。普通区间裁剪不能承担算法创新。

仍值得具体检验的差别，是**直接对相对进度消除未知标定和非共面针体干扰量的可计算算子**，以及它是否在相同可观察证据下比通用几何集合求解更紧或更快。完整算子尚未完成，当前不具备训练条件。下一步先检查真正可见、方向语义明确的物理边是否能提供不依赖隐藏顶点ID的约束，再在下述最小固定状态核上构造连续读数外界；完整1506门槛通过之前，不进行正式训练。

## 最小固定状态可行性核

另已实现一个有限构造原型：对一条**经验证平行于盘面的有向直边**，其方向投影为

`V = H [cos(−uλ+β), sin(−uλ+β), 0]ᵀ`。

u为相对进度，λ为刻度跨度，β为该物理边的模板方向。不同边允许处在不同高度；单条边必须确实平行于盘面，不能用任意Hough线或轮廓代替。若a→b为该边的正向端点，正深度给出`V = α[b,1] − γ[a,1]`、α和γ为正。对端点矩形集合可将其写成矩形角点射线的锥组合。在固定u、λ时，这些约束及刻度像素盒约束线性于H和锥权重，边的高度和平移无需作为输入。

三条不同高度的合成有向边验证了这个核：真实u=0.37、λ=180°在精确观测和连续坐标±0.5px盒中均数值可行；固定错误u=0.47、同一跨度在精确观测下返回数值不可行。独立脚本核对全部线性约束和保存原始解，最大原始残差低于4.3×10⁻¹²。3次LP求解的内部计时为0.016245秒。

这仍只是固定状态的**必要条件外松弛**，允许退化H及零锥权重。数值不可行不是精确Farkas证书，有限状态检查也不是连续读数外界。实际针型是否具有可见、可定向的合格边，以及如何在未知边身份和连续u、λ范围内保持覆盖，仍是下一门槛；不能把这个构造当作已验证的新算法或RGB结果。

## Limitations

这些是固定合成模型的有限见证，不是实际1506张上的错误频率，也不表示两幅完整RGB图像不可区分。不同解释允许不同未知内参；没有证明已知且相同相机内参下仍有同样歧义。反例不隔离此前9张新增错误的唯一原因。

包含真实读数的**区间**投影有条件地不增加绝对误差；投影到不连续集合没有这个一般保证。有限求解样本的最小／最大值只是内采样，不能当成覆盖外界；高边际覆盖率也不保证普通集合逐图无新增错误。定向查新不等于全领域新颖性认证。

本阶段没有重新求解原1506张，没有CNN前向、GPU调用、训练更新或扩种子。6次合成几何搜索的内部计时为0.069243秒，不包含Python导入、SSH或未来RGB证据提取；没有将其当作camera端到端速度。当前最佳已完成RGB参照仍是普通监督MobileNetV4 best63。
