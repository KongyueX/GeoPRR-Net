## Limitations

真值组合是离散标签与组合算子的核查，不是学习模型精度。留出组合边共享已见图像、状态和布局，不能充当新图或新布局测试。新增组只使用一个源训练许可 HDR，不能证明跨背景或真实域泛化。本轮未记录 GPU 精确峰值，四图探针的显存采样不能代替全数据峰值。
