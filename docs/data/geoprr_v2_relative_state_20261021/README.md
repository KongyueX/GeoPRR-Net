# 相对物理状态分布：完整65轮源验证负结果

**该候选未通过冻结门槛。**seed 20262020的joint完成65轮，按完整1506张源验证native NMAE选中epoch 60。NMAE为**0.4533216657%FS**，普通监督模型native为0.1479240671%FS、固定r8为0.1299504985%FS；相对增加206.4557%和248.8418%。最大误差升至82.8413169831%FS，>2/>5%FS为62/21张，普通1495张均值也升至0.3727221250%FS。控制器按预先规则跳过independent，未扩seed或运行official test。

正确的逐顶点物理标签及网格读出已经通过[完整零训练接口检查](../geoprr_v2_physical_interface_20261021/README.md)，但本次RGB模型没有把该接口的可行性转化为识别收益。当前已完成模型中仍保留普通监督MobileNetV4 best63作为参照。

## 模型、训练与成本

模型仅接收RGB ROI，使用普通监督best63的共享MobileNetV4/FPN初始化，再用一个空间状态头预测两分量δ/λ混合分布，按冻结物理映射把完整质量推送到进度空间。δ为圆周256点，λ为含0和2π端点的有序256点；无效λ端点质量均匀计入读出，不删除或条件归一化。目标为结构状态NLL加原读数CDF；训练标签使用额外几何信息，推理不接收H、相机或模板。

## 判定与证据边界

完整1506有效性通过，其余九项精度、普通保护、严重病例和新增错误门槛全部未通过，决策为`joint_validation_rejected`。按冻结顺序，independent未运行，所以当前不能测出joint相对独立边缘组合的增益，也不能把这次具体实现的失败推广为所有联合状态或物理读出思路无效。

这里明确否决的是已运行的RGB候选：当前空间池化状态头、训练目标、warm start和全概率均值组合未能保住普通精度，也未减少重尾。正确的物理教师只证明标签与读数接口可用，没有证明RGB识别可学、几何状态可靠或方法具备论文贡献。下一次候选须根据实际失败机制重新形成可验证设计，不通过改窗口、门槛或扩seed复活本结果。

## Limitations

单seed源开发结果，不提供跨seed样本标准差。源验证已经反复查看；没有新增official test、真实域冻结迁移或论文级新颖性结论。新头使用更多结构监督和继承初始化，与旧普通监督在信息、目标和累计训练成本上不同；未执行independent使配对贡献无法识别。公开包不含RGB、模型权重、原始顶点/相机几何或服务器私有路径。
