## Limitations

新结构与source mean-tail R同时改变，不能单因素归因attention；较好的源tail也没有转成整体外域收益，不由一个case否决方法或论文。复用源数据不意味着完整模型部署合同与v16相同。共享HDR的roll验证不是新域盲测，没有旧模型按新R重新选择的counterfactual baseline；历史GeoPRR像素／完整权重链未认证。两外域已查看、单seed不支持SD、显著性或普适机制声明，常规attention与文献动机不构成新理论。所有原14494／1506／4000、fixed cohorts、旧模型／G1／anchor／65轮和负结果保留；RGB、权重、H／C／XYZ／field／bbox、特征矩阵、完整源合同／人口及private trace不公开。本轮不自动升模型，也不机械延长或扫参。
