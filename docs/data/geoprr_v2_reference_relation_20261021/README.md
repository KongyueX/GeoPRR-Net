# 参考条件联合读数：结构与标签准入

完整1506个理想角色标签的读出量化检查通过，RGB网络和同参数product对照已经实现，尚无新模型准确率。正式实验方法与准入／停止规则见[冻结协议](../../GEOPRR_V2_REFERENCE_RELATION_PROTOCOL_CN.md)。

## 实际网络差异

保留MobileNetV4／FPN；四参数角度线束整形与局部径向嵌入形成256个角色token。网络先给出起点分布A，再对每一个起点解释匹配虚拟读数点与终点，生成条件相对分布P_rel、B_rel。

`J=P_relᵀ diag(A) B_rel`保留同一个起点变量。product对照以相同条件地图求边缘再相乘，参数、监督与曝光相同。完整模型7,461,060参数，其中29,812属于新头。

这一区别超过单纯径向池化，但仍属于待验证的任务专用关系结构。三重相关、共享参考相关性和一般条件图模型运算均有先例，不作为新定理或已确认的论文创新。

## 构造与接口检查

四个圆周算子检查通过，覆盖归一化、直接求和／FFT符号、共同整数位移、共享参考与重复参考的区别，并明确保留独立三边缘分布丢失配对的反例。无条件三重相关的FFT实现只用于算术对照；条件网络实际采用矩阵乘法。

条件匹配模块的四个生成token检查通过，验证完整质量与梯度、共同位移不变性、不同起点解释下的配对能力，并保留同一起点下仍会交叉错配的反例。实际执行4次未训练模块前向、7个生成样例、1次反传，未优化。

完整RGB类的三个CPU检查通过，覆盖Torch／NumPy全质量读出、半像素教师标签和一个未训练64×64生成RGB前向／新头反传。模型参数／初始化选择与两臂一致。另有针对性数据合同检查覆盖逐行路径／监督变更、配对曝光以及验证输入失败完整保留。

上述生成输入检查不是源图准确率。实际best63共享权重、原始名单及零优化GPU runtime属于另外的准入记录，不从这些单测推导训练成功。

## Limitations

条件网络仍采用pointer与end在给定起点／图像后独立的假设。同一个起点若对应多组相关解释，仍可能产生错误交叉状态；错误局部证据也不会被代数自动修复。参考点近乎点质量时，joint与product可变得相同，届时不能将收益归给联合机制。

四参数恢复角度线束，不恢复完整半径或针体高度。虚拟pointer phase不是物理针尖，经验查询射线不是针体。未运行新官方test、真实迁移或额外seed，源验证为反复查看的开发人口。
