## 实际网络差异

保留MobileNetV4／FPN；四参数角度线束整形与局部径向嵌入形成256个角色token。网络先给出起点分布A，再对每一个起点解释匹配虚拟读数点与终点，生成条件相对分布P_rel、B_rel。

`J=P_relᵀ diag(A) B_rel`保留同一个起点变量。product对照以相同条件地图求边缘再相乘，参数、监督与曝光相同。完整模型7,461,060参数，其中29,812属于新头。

这一区别超过单纯径向池化，但仍属于待验证的任务专用关系结构。三重相关、共享参考相关性和一般条件图模型运算均有先例，不作为新定理或已确认的论文创新。

## Limitations

条件网络仍采用pointer与end在给定起点／图像后独立的假设。同一个起点若对应多组相关解释，仍可能产生错误交叉状态；错误局部证据也不会被代数自动修复。参考点近乎点质量时，joint与product可变得相同，届时不能将收益归给联合机制。

四参数恢复角度线束，不恢复完整半径或针体高度。虚拟pointer phase不是物理针尖，经验查询射线不是针体。新架构、结构监督和warm start均与普通监督不同，未运行product训练，不能将全部收益归给联合机制。结果仅为单seed、反复查看的源开发人口；未运行新官方test、真实迁移或额外seed。该候选在总体精度上优于旧参照，但严重误读保护门槛未通过。
