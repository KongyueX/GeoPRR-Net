## 数据与训练设置

复用各种子已完成的 16,000 张、60 轮 RawEff 基座；ReMST、R2MT、polar 和最终 router 均在完整 16,000 张源域训练图像上拟合。ReMST 5 轮，R2MT 专家和 router 各 40 轮，polar 10 轮，最终 router 40＋120 轮、96,000 条图像条件记录。共同 warm 初始化沿用原 A 集权重。

三种子及各比较器的样本、六条件、标签和源组逐行对齐；原 Geo 和 RawEff 直接读取已保存的正式预测。全部九个统计范围的 NMAE、Acc@2、Acc@5、覆盖率、失败数见 JSON 和 CSV。

- `full_three_seed_per_seed_metrics.csv`：三种方法、三个数据集、九个范围的每种子指标。
- `full_three_seed_mean_sample_sd.csv`：对应的三种子均值及样本标准差。
- `full_three_seed_paired_comparisons.csv`：原始图与六条件的组配对比较。

## Limitations

目标域已有历史开发可见性，本次属于探索性比较。组 bootstrap 区间描述固定三种子平均结果的组间不确定性，不包含重新训练的种子不确定性；后者由三种子样本标准差单独描述。共享方案的基座与后续模块使用重合的源域训练图片，共同 warm 初始化仍来自原 A 集。
