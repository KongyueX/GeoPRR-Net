## Limitations

本阶段是描述性缓存分析，不是组件训练因果实验。高熵／L1的rank不是可靠路由器；保存Jproduct不是Fsep。固定质量上界不排除上游概率错误。所有GT条件只用于后续诊断，不能作为部署输入或新RGB性能。模型seed、人口、原门槛与已拒绝的separable控制不变。
