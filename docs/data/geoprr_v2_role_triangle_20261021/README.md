## Limitations

本结果仅唯一seed、反复查看的源开发人口；没有显著性、盲测、真实迁移或跨seed证据。separable训练被冻结门槛跳过，与best48比较还包含继续优化和曝光，不能将全部收益归给新增P—B关联。三角图模型与双线性匹配已有先例，当前结果不足以认证论文核心创新。

普通聚合误差及最大误差改善，与新增严重错误并存。原11项及best48保护均未完整通过，当前模型不能称robust-approved。GT条件诊断、教师量化、实现准入和训练结果分开记录。

资源准入两臂顺序执行，首批／缓存状态不同，其stepwall不能作为两臂速度比较；零优化准入未分配Adam矩状态且有效batch固定64，峰值不替代正式完整成本。准入separable调用不等于启动过separable正式训练。
