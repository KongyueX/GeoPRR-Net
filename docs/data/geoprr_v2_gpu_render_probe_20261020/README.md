# CUDA 受控多状态渲染与标签契约探针

Blender 4.5.14 LTS 已在 NVIDIA RTX PRO 6000 Blackwell Server Edition 上完成一组 4 张受控图像的 CUDA 渲染，采用 1920×1080、200 samples/pixel、JPEG quality 95。该组只改变同一根指针的旋转，布局、外观、相机及其他已记录因素保持一致。4×4 次真值场组合的最大误差为 **0.00007510185%FS**，支持使用这一设置继续构建独立的受控组。

本记录的协议为 `geoprr_v2_gpu_render_quality_probe_v1`，生成种子 `20262020`，归一化状态为 `0.15、0.35、0.65、0.85`。原始训练、验证与官方测试名单不变。

## 渲染耗时与内存

| 指标 | 实测值 | 测量边界 |
|---|---:|---|
| 第 1 张调用耗时 | 3.32 s | Blender 日志的单图 Time 值 |
| 第 2 张调用耗时 | 3.37 s | 同上 |
| 第 3 张调用耗时 | 3.41 s | 同上 |
| 第 4 张调用耗时 | 3.34 s | 同上 |
| 四图调用均值 | 3.36 s | 上述四个 Time 值的算术均值 |
| 后三张调用均值 | 3.3733333333333335 s | 第 2–4 张的算术均值 |
| 整组 Blender 进程墙钟时间 | 18.548555 s | 启动、场景构建、四次渲染、因子一致性检查和标签导出 |
| 采样显存最大值 | 4452 MiB | 每秒查询一次 Blender PID 的 used_memory，共 12 个有效样本 |

整组 Blender 墙钟时间不包含随后独立运行的几何诊断进程。单图 Time 值不能代替包含启动和场景构建的完整流程耗时；4452 MiB 是离散采样最大值，不能称为精确峰值。

## 几何与受控关系

- 四个图像状态的 render 前后因子检查均通过；只有选定指针的状态发生干预。
- 真值 U/M 与共同相机的固定关系相同，最小真值支持质量为 1.0。
- 16 次真值组合包含 4 次自身组合和 12 次跨状态组合。最大归一化误差为 `7.510185241477174e-7`，即 `0.00007510185241477174%FS`。
- Q 指共同表盘面的虚拟读出位置；可见针尖 `outside_kp` 保留其真实针尖含义。

## Limitations

本探针只有一个布局、一个外观和一个固定相机，不能代表所有布局、视角和材质的渲染吞吐，也不能给出全数据集成本或精确 GPU 峰值。16 次组合使用几何真值，并非训练模型的预测；本记录没有模型性能、泛化或真实域结论。技术设置已经能够执行这一受控组，但正式数据仍需要独立的布局划分、完整因子记录和各组标签核查，不能将四图探针认定为正式训练集已生成。
