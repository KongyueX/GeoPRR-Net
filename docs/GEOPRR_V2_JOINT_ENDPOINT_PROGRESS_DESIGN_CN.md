# 联合针体关键点到物理进度的概率推断

## 研究判断

保留一个直接修改MobileNet读数机制的候选：**在表盘标定坐标内保留针体两个关键点的联合概率，再对共同位置边缘化，输出物理进度分布。**它替换孤立虚拟读数点Q的接口，不依赖新增整模型专家或路由器，也不把一致性loss作为主要改进。

当前尚无新模型结果，不能宣称已取得论文级创新。联合关键点、mixture density、位移相关与几何概率推断都有强近邻；候选差异只保留为一个可被否证的问题：端点相关信息能否以可计算的几何边缘化保留下来，并提供独立端点、角度分类或针线拟合没有的严重误读纠错能力。

## 需要解决的实际问题

[完整1,506张GT-atlas/frozen-Q诊断](data/geoprr_v2_gt_atlas_20261020/README.md)表明，正确标定可以修复sync_338，却不能修复sync_10202的错误Q峰；sync_4515则有接近真值的峰，但大范围错误质量污染读数。现有三个完整模型的[理想逐图选择](data/geoprr_v2_failure_complementarity_20261021/README.md)仍未救回普通监督r8的任何>2或>5%FS错误。

这支持优先改变指针证据的表达。它没有证明新关键点头一定能在反光或低对比图中恢复正确证据，也没有证明原骨干保留了足够信息。

## 单一机制与数学接口

```text
RGB ROI → 原MobileNet/FPN → 表盘坐标内的端点联合概率
                                ↓
                       对共同位置求和，保留位移分布
                                ↓
                       位移方向 → 物理进度分布
                                ↓
                       预先冻结的native/r8读出
```

标定映射记为T：image/ROI→metric canonical。若代码中已给出这个方向的H，不再求逆。两个针体标注点分别映射为o=T(origin)、t=T(outside)，再取d=t−o。不能先在图像内相减，再把位移当作一个位置送入homography。

现有`Pointer.origin_kp`、`Pointer.outside_kp`只是标签字段，不能据字段名假设已有可见性、遮挡或真正针尖标签。它们是否属于同一针平面、能否给出准确方向，是第一道零训练验证。

### 联合概率而非两个独立热图

在同一canonical特征格上预测

\[
P(o,t\mid I)=\sum_{r=1}^{R}\alpha_r(I)A_r(o\mid I)B_r(t\mid I),
\]

其中各A、B为归一化非负PMF，α位于simplex。最小候选取R=2，只提供超出独立端点的最低表达能力，不展开rank搜索。直接在校正后的特征格预测PMF，避免把普通图像双线性采样误当概率质量守恒推送。

同一分量内条件独立，整个mixture可保留端点相关性。共享mixture分量不是图像类别专家，不为每个分量设置独立encoder。

R=2只提供表达两个配对模态的能力；若同一分量的A或B仍有多个峰，分量内部仍可能出现伪配对。不能把rank选择本身当作排除所有错误配对的保证。

位移后验为

\[
D(d\mid I)=\sum_oP(o,o+d\mid I)
=\sum_r\alpha_r(A_r\star B_r)(d).
\]

完整线性互相关可用R次FFT实现，无需构造N²个端点对。对H×W格必须保留至少(2H−1)×(2W−1)的线性相关范围，不能使用循环相关产生跨边界假位移。复杂度约为O(RN log N)，存储约O(RN)，均为符号量级，不是已测延迟或显存。

最后将d的方向按标定起始方向和有符号弧长映射到物理进度g(d)，以固定two-hot权重推送到K=256 bins。不同长度但相同方向的位移应进入相同进度；先平均端点或位移再求角度会改变推断对象。

### 为什么配对信息有可验证内容

手工例有两个等概率假设：o1=(0,0)、t1=(2,0)，o2=(0,2)、t2=(2,2)。两个正确配对都指向位移(2,0)，但把联合概率拆成同边缘的乘积后，会产生o1/t2和o2/t1两种伪配对，各有1/4质量，方向分别偏向±45°。

该例说明相关性在数学上不能由两个边缘恢复。它不证明当前模型学到了正确相关性；此例中两个端点的均值差也恰好正确，不能用它声称击败所有点估计。未来最关键对照是使用同一学到的P，拆成P(o)P(t)后保持其余推断完全相同。这样改变的是配对信息，而非骨干、标签或头容量。

## 几何范围：共同位置可以消去什么

令表盘平面为z=0，相机P=[p1 p2 p3 p4]，H0=[p1 p2 p4]，a=H0⁻¹p3。针体两个点位于平行平面z=h。经表盘逆映射后

\[
u_h(X)=\frac{X+h a_{xy}}{1+h a_3},\qquad
u_h(T)-u_h(O)=\frac{T-O}{1+h a_3}.
\]

在分母为正、两点同高、平行平面及有效投影假设下，共同平移消去，差方向与高度无关。常见针平面位于表盘与相机中心之间的物理位置可满足正号；仅有正相机深度不足以代替这个假设。分母为负时有向方向翻转π，不能用于同一有向读数。因此无需为单图再估计不可辨识的针高度。该代数推导不是CNN射影等变性，也不保证学习得到的联合分布在图像扰动下保持不变。

若两点高度不同、针体弯折、标签不是所假设的物理点，或标定错误，则结论不适用。必须先用GT点、GT标定与原目标核对完整人口误差，不能先训练再以额外自由形变掩盖几何失配。

## 异常质量和读出合同

完整位移后验总质量保留。零位移、非有限映射与canonical溢出进入无效原子p⊥；不删除后只评价剩余质量。弧外方向沿冻结角度展开后按最近端点clip到0/1，同时报告端点质量，不能把弧外样本去掉。

未来协议必须在训练前冻结含无效原子的scalar决策。native/r8只处理进度部分，但逐图同时保存原始有效质量和p⊥；全部质量无效或几何计算失败的图保留error=1及完整分母。r8的峰选择不提供置信保证，不以低p⊥筛选子集作为主成绩。无效质量很小时如何影响最终决策仍需在实现协议中明确，当前不是完整部署算法。

此处native指新进度分布的期望解码，不表示新头仍经过原Q/U/M支持门槛与direct路径。原模型对照保留原路径；若将新头作为修复器接回旧读出，其支持、回退和成本合同必须单独写清，不能借用相同名称掩盖计算差别。

## 与现有方法的区别及已有覆盖

| 方法 | 已有机制 | 本候选实际改变的对象 |
|---|---|---|
| 角度分类 | 从图像特征直接输出角度/进度类别 | 显式建立两点联合分布，再推送为进度；是否必要由同信息角度头决定 |
| Hough / Deep Hough | 在候选线或参数空间累积特征/投票 | 从归一化的相关点对分布边缘化共同位置；相关运算本身不作为创新 |
| 针线拟合 / 两点读数 | 先确定点或线，再算方向 | 在算进度前保留配对歧义，不先固定一条针线 |
| 独立端点热图 | 两个位置边缘分布或分别argmax/均值 | 保留能被同边缘乘积消除的配对相关信息 |
| 通用联合关键点模型 | 联合坐标、pairwise约束和概率推断 | 特定几何下从联合位置直接边缘化为进度，以及相应成本和必要性 |

必须正面对照的一手工作如下：

- [Howells等，CVPRW2021](https://openaccess.thecvf.com/content/CVPR2021W/MAI/html/Howells_Real-Time_Analogue_Gauge_Transcription_on_Mobile_Phone_CVPRW_2021_paper.html)：已有表盘rectification、关键点及parallax处理，其针点标签投影到表盘背面。不能把标定后关键点读数或视差处理本身作为新意；也不能把本方案的同高物理点接口误称为该文完全相同的标签合同。
- [MDPose，UAI2023](https://proceedings.mlr.press/v216/seo23a.html)：已有mixture density建模关键点联合分布及关键点似然训练。联合建模、mixture和利用关键点相关性均不是独立创新。
- [Adaptive Graphical Model Network](https://arxiv.org/html/1909.08205)：已有图像条件下的unary、pairwise位移势和可微图模型推断。不能把两个关键点增加成对约束作为新算法。
- [PDC-Net，CVPR2021](https://openaccess.thecvf.com/content/CVPR2021/html/Truong_Learning_Accurate_Dense_Correspondences_and_When_To_Trust_Them_CVPR_2021_paper.html)：已有概率位移、mixture不确定性和相关特征。位移分布与相关层本身均已有。
- [Deep Hough Transform，ECCV2020](https://arxiv.org/html/2003.04676)：已有深度特征在线参数空间聚合。改成深度针线投票不足以成为新贡献。

可继续核查的候选贡献只有：**以可计算的相关端点概率表示，保持配对信息，并在物理几何下精确边缘化共同位置得到进度，证明这种信息对严重误读有独立作用。**低秩分解、FFT恒等式与双平面差分各自均为已知工具，不主张为新定理。若这只是联合关键点模型的任务特化且普通强对照复制收益，停止方法创新主张。

## 三块最小验证

以下均为计划，当前未启动训练或新前向。

1. **零训练物理接口。** 在完整1,506标签上检查T(origin)、T(outside)之差与原物理进度的误差、覆盖与无效数；用手工概率验证联合/独立配对差异及线性相关质量守恒。GT几何结果单列，不能充当模型成绩。若标签几何本身产生显著严重误读，停止该接口。
2. **关联信息必要性。** 未来获授权后，仅同seed、同GT标定条件的小头验证。使用同一个联合头分别做完整P推断、同边缘乘积推断、端点均值/argmax推断，并以rank1和同信息普通角度头作能力对照。沿用明确的关键点监督，不通过额外loss菜单创造差异。若完整P没有超出这些对照的纠错，停止联合概率贡献。
3. **自动几何与完整严重误读。** 前一步通过后，所有方法共享同一预测标定和数据角色，比较普通监督native/r8、针线/关键点读数、角度头及本候选。逐图报告NMAE、Acc@1/2/5、>2/>5、rescues/regressions、tail10、最大误差、p⊥与成本。不能以均值下降掩盖新增严重错误，不能只报告GT标定或已知难例。没有新增纠错能力就不训练router，不扩种子。

未来若需要故障分工，将该机制作为Q修复候选，并与[标定/指针因子修复](GEOPRR_V2_FAILURE_COMPLEMENTARITY_DESIGN_CN.md)的四动作能力比较。选择器不是当前主贡献，也不提前训练。

## Limitations

当前没有联合头、预测标定或真实迁移的学习结果，只有既有模型诊断与数学构造。联合模型仍可能把两个端点一起错配到反光结构；FFT不会补回图像中未提取出的针体信息。单对标签不能保证mixture分量不塌缩或具有可解释意义。物理点语义、同高假设、canonical覆盖、无效质量决策与通用pairwise模型的必要性均需先核对。该方向是可具体否证的算法候选，不是发表保证或已通过的新颖性认证。
