# 相对状态负结果：冻结checkpoint诊断协议

## 目标与范围

[完整65轮候选](data/geoprr_v2_relative_state_20261021/README.md)已经失败。此诊断区分相对针角δ、刻度弧长λ及其概率组合的条件修复空间，不能据此重选checkpoint或把GT干预作为新自动模型。

固定seed20262020、原best60、原完整1506张源验证及原预处理。仅执行一次全人口RGB前向，batch32、eval、原FP16 AMP配置；优化步、训练、其他seed和official test均为0。离线几何标签只用于前向后的计分和条件干预，模型输入仍仅RGB。

## 四个固定读出

| 名称 | 联合状态输入 | 含义 |
|---|---|---|
| joint | 原模型输出Q(δ,λ) | 原正式读出的重放 |
| product marginals | Q沿两轴求和后的边缘外积 | 同一个拟合模型对依赖关系的敏感性 |
| GTδ × predicted λ | 圆周两热GTδ与预测λ边缘的外积 | 正确δ下λ预测的条件修复空间 |
| predicted δ × GTλ | 预测δ边缘与有序两热GTλ的外积 | 正确λ下δ预测的条件修复空间 |

四者均使用已冻结256×256物理推送和完整概率均值。λ=0、2π端点的质量均匀进入进度分布，弧外质量保留并按原端点裁剪；不删质量、不按GT择峰、不重分配混合权重、不调窗口、无direct或旧模型回退。已有GT双状态网格结果直接连接，不重复GT几何计算或新增模型前向。

## 重放与输出

原joint逐ID核对原正式best60的target、valid状态和prediction；最大读数差不得超过归一化1e−5，即0.001%FS。超限保留当前产物并先查checkpoint、预处理和AMP差异，不能覆盖原正式结果，也不据漂移后的结果宣称修复。

缓存仅保留每图两分量权重及δ/λ分量PMF、对应ID和标签，不保存完整joint或全分辨率attention缓存。由它们可以在无新网络前向的情况下复算四条路径。

状态诊断包含δ的圆周均值、argmax及误差、圆周合成向量长度，λ的有序均值与argmax及误差，两轴GT邻接bin质量和熵，以及分量误差、分量分离度、invalid/outside质量。圆周向量近抵消时，均值方向不能解释为高置信错误方向。

输入或数值失败在每条路径均保留error1，完整分母仍为1506。分别汇总全体、共同普通1495、r8普通1497、原严重6张、候选全部>2/>5及新增错误名单，报告NMAE、Acc@1/2/5、>1/>2/>5、median/p90/p95、worst151/max与逐图rescues/new。正式原模型结果始终保留，条件干预不参与模型排序。

另记实际图像前向数、优化步数、网络与原读出wall、条件读出wall、完整进程wall和显存边界。数据加载、状态计分及导出包含在完整进程wall中，没有独立计时；该诊断的batch吞吐不作为batch1或相机端到端延迟。

## 数值验证与决策

新增数值检查仅覆盖干预导出：δ跨零缝两热守恒、有序λ接近2π的端点质量、三种外积的完整质量与冻结读出，以及失败行完整保留。完整前向后用缓存PMF独立复算，不导入原汇总器确认关键算术。

同checkpoint边缘乘积不能替代未训练的匹配对照，也不能证明联合训练的因果收益。GT单轴替换只反映条件修复空间；两项均能救回或均无法救回时，不能把非线性交互强行归因给单一变量。下一核心机制应针对诊断确认的可观测阻断，再形成具体模型合同与零训练/可部署验证；本协议不启动新候选训练。
