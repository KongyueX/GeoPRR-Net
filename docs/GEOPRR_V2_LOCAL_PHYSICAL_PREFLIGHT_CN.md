# GeoPRR局部物理接口与未知标定门槛

完整1506张名义无扰动验证否决了“仅由有序刻度点确定一个标定，再串行解针方向”的部署路线。给定正确G与间隔的逐高度材料接口通过，但估计标定链NMAE为0.693434807%FS、最大45.683515%FS，明显差于普通监督MobileNetV4固定r8的0.129950499%FS、最大19.557136%FS。没有据此启动新训练或扩seed。

## 冻结输入和材料选择

原train/validation/test=14494/1506/4000不变。本次使用原完整1506源验证，普通集合为旧native和r8误差均≤1%FS的1495张，以及r8≤1%FS的1497张；旧严重集合为两种旧读出>2%FS的6张并集。读数只在所有目标盲预测保存之后加入。

模板选择在计分前冻结，排除精确z组内至少8点且满足质心/圆周/协方差各向同性容差1e−6的hub圆周，保留其他所有材料点。pointer1/2/3保留18/12/408点，共222054个材料对应。各点保留自己的高度；最高平面和窄针尖同高点对没有被作为统一接口。该选择只依赖模板几何，不依赖严重图或读数误差。

针体假设为已知材料XYZ、绕共同z轴的proper rotation、正尺度和共同平移。若G已映射到metric刻度平面，则

`w_j(1−b z_j)=κRθ[X_j,Y_j]ᵀ+t−a z_j`。

这里a、b为相机相关干扰参数，不输入GT C。7参数线性系统只初始化；最终以全部源像素重投影误差拟合，检查κ>0及所有`1−b z_j>0`。不能以无权代数残差代替真实像素残差，也不保证未知三维倾斜或变形下成立。

未知标定链在正确、完整、有序、连续等角刻度假设下拟合全部N点。N=7–36满足精确数据下N≥5的可辨识条件；固定单位圆和首刻度规范后，五点conic cross-ratio可初始化间隔，再用所有点像素残差求H和span。数学可辨识不消除整数点误差及短弧退化。

未知链在共同普通1495张上mean/median/p90为0.685264734/0.062972116/1.475604948%FS，新增207张>1、115张>2、40张>5错误。两条链都把旧6张严重样本救到≤1%FS，不能因此忽略未知链的大量新增错误。

最大错误为`sync_8861`。数值病态病例`sync_15021`的估计span接近零、H条件数约3.32×10¹³，保存H/G之间的重投影差异最高0.249400px。独立审计核实全1506保存读数、分母及计分，并把未知链标为WARN；未发现固定初值近等残差替代解，不构成唯一性或可靠置信度证据。

## 观测语义和下一门槛

两条链仍输入GT材料/刻度位置及模板身份，可见性未知，不是自动RGB成绩。刻度mask也不能直接补成径向边：源代码对立体cube全部顶点取投影坐标极值，完整73162列表实际有4/5/6点三种形状，没有固定顶面、角点或long/short身份。直接将它们当共面矩形会引入新的未经验证前提。

因名义未知标定已失败，没有继续完整1506的扰动、缺失、假峰压力测试。下一方法须共同利用真正可观察的标定与针体证据，保留标定的不确定性，并通过同样普通精度、旧严重、新增错误及tail/max门槛；不能以低刻度重投影残差或理论唯一替代读数验证。经典标定、针线拟合和概率几何本身不构成新颖性认证。

两个CPU全人口解码进程为16.599261s和25.165829s，0 CNN、0模型更新、0新seed，未包含未来检测和camera端到端成本。数据、全部指标、完整逐图、复核WARN、冻结索引和复算入口见[公开规范化结果](data/geoprr_v2_material_geometry_20261021/README.md)。

## 共同观测基线的完整检查

在相同GT材料／有序刻度观测下，进一步用16参数共同拟合H、跨度与逐高度针体，优化同一个完整源像素SSE，不输入GT H/C/间隔/span/读数。完整1506结果为NMAE0.143349636%FS、>1/2/5为28/9/0、worst151为0.800913500%FS、最大3.194441236%FS；旧严重6张全部≤1%FS。共同普通1495张mean升到0.142718900%FS，并新增28张>1、9张>2错误，因此冻结门槛未通过，不启动训练或追加压力矩阵。

四固定起点均保存，最终按收敛且物理有效的像素SSE选择；没有按读数目标选解。近等成本起点读数一致仍未保护普通样本，说明继续增加初值或用低重投影残差当置信度不能替代可观察证据检查。联合最小二乘本身不是新算法贡献。完整逐图、6024起点、独立复核WARN边界及成本见[共同观测基线结果](data/geoprr_v2_joint_observation_20261021/README.md)。
