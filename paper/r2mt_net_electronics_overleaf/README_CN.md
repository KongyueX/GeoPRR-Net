# R²MT-Net Electronics 稿件说明

本目录是当前唯一现行的 `Electronics` LaTeX/Overleaf 稿件包。论文已改为以 R²MT-Net 端到端仪表读取系统为唯一主线：检测获得仪表 ROI，R²MT-Net 预测归一化指针进度，OCR 识别有序量程端点，最后换算物理读数。

## 当前叙事边界

- R²MT-Net 是唯一主模型名称；旧内部名称不再出现在标题、摘要、主结果表或主性能图中。
- 原内部基础检查点只在消融表注中出现一次，用于仓库结果追溯，不被描述为另一套论文模型。
- 四项创新均从实际失败问题出发：OCR 端到端换算解决“进度不是物理读数”；关系编码双视图传输解决投影后的支持与指针--刻度关系不一致；多风险矩仲裁解决单一均值/尾部/严重条件目标无法同时覆盖；先合并矩残差再做一次精确传输解决后验概率直接混合导致的形状不一致。
- 原始视图与支持归一化视图的关系编码、几何有效性判断和恒等回退属于 R²MT-Net 本体，不单独包装成另一模型。
- 保留既有 OCR 端到端结构。OCR 不是论文重点，数值只报告通过量程有效性检查样本的 `Acc@5%FS`。

## 已完成且可写入正文的证据

- SyncG 拟合：14,442 张图像、131 个场景组；其中 6,616 张图像、60 个场景用于关系传输阶段。
- 回顾性场景分离评估：1,558 张图像、14 个场景、三次独立拟合。
- R²MT-Net：六条件 NMAE 为 `1.0517±0.0415 %FS`，投影条件池为 `1.3099±0.0501 %FS`。
- 相对匹配的 EfficientNet-B0 端点分别下降 24.53% 和 33.58%。
- 相对内部基础关系传输分别下降 9.42% 和 14.31%。
- 固定三风险先验已经获得绝大部分增益；表征条件路由只被解释为小幅保守修正。
- 将三个已传输后验直接做概率混合会恶化到 `1.1882±0.0987 %FS` 和 `1.5829±0.1651 %FS`，因此“单次最终传输”是最强的机制证据。
- 工业实拍：1,395 个 ROI、52 个来源组，已完整纳入 R²MT-Net、Direct-ResNet18、EfficientNet-B0 和 MobileNetV3-Large。R²MT-Net 相对同骨干 Direct-ResNet18 在全部/投影条件下降 `3.2954` / `6.6342 pp`，对应 95% CI 为 `2.0864–4.4153` / `4.3215–8.8624`；但 EfficientNet-B0 的工业全部/投影均值更低（`15.2550` / `18.0914 %FS`），正文明确写成跨骨干域反转而非普遍最优。
- VDN 同像素交集：129 个样本、6 个场景、774 行。R²MT-Net 在全部/投影条件为 `0.9054±0.0392` / `1.2140±0.0714 %FS`；标注辅助的单检查点 VDN 参考为 `1.6444` / `2.1030 %FS`。该比较只支持方向组件，不是自动系统排名。
- OCR 已接受样本：`Acc@5%FS = 74.07±12.83%`（`n=9`）；不在论文中扩展报告 OCR NMAE、覆盖率或实时检测性能。
- 自然重复性：1,203 个保留样本、86 个精确读数单元。清洁条件下 R²MT-Net 与原始/SARN 端点逐项相同，验证恒等回退，不解释为性能提升。
- 匹配效率：RTX 4060、BF16、模型内计时。完整 R²MT-Net 为 11.6892 M 参数、9.582 注册 GFLOPs；batch 1 为 `22.3197 ms`，batch 8 为 `3.5657 ms/样本`。不包含 SARN 图像生成、检测与 OCR。

上述 14 场景评估集曾参与历史开发观察，正文统一称为“回顾性场景分离评估”，不称为未触碰测试集或独立确认集。

## 当前文件

- `manuscript.tex`：英文主稿。
- `references.bib`：参考文献。
- `figures/build_r2mt_figures.py`：R²MT-Net 图表与机器可读源数据生成脚本。
- `figures/r2mt_architecture.*`：模型结构图。
- `figures/r2mt_ocr_pipeline.*`：保留的 OCR 端到端结构图；条件精度只在正文短段落中报告。
- `figures/r2mt_core_performance.*`：六条件四模型主性能、条件相对降幅和匹配差值图。
- `figures/r2mt_ablation.*`：六条件模块开关、配对效应和路由强度消融图。
- `figures/r2mt_industrial_validation.*`：工业实拍四模型条件曲线、配对效应热图和聚合森林图。
- `figures/r2mt_vdn_validation.*`：VDN 同像素条件对照与配对效应图。
- `figures/r2mt_efficiency.*`：分阶段时延、batch 收益与参数量--计算量图。
- `figures/source_r2mt_*.csv`：所有正文图表的紧凑机器可读源数据；OCR 文件只含已接受样本条件指标。
- `R2MT_EXPERIMENT_GAP_AUDIT_CN.md`：补实验优先级、指标和论文可写结论边界。

## Overleaf 编译

1. 将本目录上传至 Overleaf；
2. 将主文件设为 `manuscript.tex`；
3. 使用 pdfLaTeX；
4. 运行 BibTeX 后再次运行 pdfLaTeX 至交叉引用稳定。
